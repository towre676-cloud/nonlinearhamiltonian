# Mandatory counterexamples and scope boundaries

For H=q³p³ and G=q²p¹⁹, the third correction vanishes but the normalized Moyal bracket is 51q⁴p²¹+(8721/4)ℏ⁴p¹⁷. A third-order-only test must not certify arbitrary higher-degree Hamiltonians. The new bridge checker evaluates the defining star exponential independently.

For H=qp³ and G=q², one bracket is exact, yet the next classical iterate K={H,G} has normalized Moyal correction 18ℏ²p². Any algorithm that deletes escaping monomials in a degree window can certify a false dynamic core. The Weyl operator method avoids that projection.

A present difference target d can discard a common nuisance c. Under an allowed action d'=c+d, c becomes future-relevant. The observer example exports an explicit hidden-state/action witness; a valid summary must respect every allowed action and the chronological word convention.

The matrix diag(1,1/1000) is invertible. Recovering the second coordinate can amplify its observation error by 1000. Rank certificates and noise bounds answer different questions. The observer's seed certifies exact factorization; the proposed PSD layer must certify amplification separately.

The integer cochain map Z→Z given by multiplication by two has degree-one cohomology Z/2. The same map over Q is an isomorphism. The rational contraction checker deliberately rejects field='Z'; a rational acyclicity receipt is not an integral result.

For a cocycle b, a zero db or zero Laplacian residual alone need not make b exact. The obstruction solver checks pb; a nonzero class has a separating functional vanishing on every boundary. A supplied differential with d²≠0 is an invalid model, not a complex with an unusually large Betti number.

A finite list of Pell solutions is complete only after the unit reduction proof covers every solution in scope. A supplied norm-one unit may be nonfundamental: classify its generated orbits and state that action explicitly. The optional arithmetic programme supplies a complete seed interval rather than interpreting search exhaustion as a theorem.
