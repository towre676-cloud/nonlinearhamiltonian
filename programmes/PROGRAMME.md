# The highest-power machinery and the next enhancement

The strongest common architecture is a target, an allowed operation, an invariant kernel or quotient, and a certificate. In finite observation, the kernel records distinctions invisible to every future target. In Hamiltonian exactness, it records observables whose higher Moyal corrections stay zero after every repeated action. In a finite complex, a contraction turns compatibility into either an explicit primitive or a nonzero obstruction. These are precise relationships between specified constructions, rather than an assertion that all domains are one theory.

## Priority: the smallest exact observer that remains sufficient

For rational actions A_a and target G, compute W_0=row(G) and W_(r+1)=W_r+sum_a W_r A_a. Dimension bounds force stabilization. A basis Q produces QA_a=B_aQ and G=CQ. The observer z=Qx is minimal among linear summaries that reproduce every requested future output from every initial state. A static initial sensor panel H suffices exactly when Q=KH. Basis rows carry word provenance, and a failed panel carries v with Hv=0 but Qv≠0.

The existing atlas implements a small fixed probe menu. The new observer seed handles rational action alphabets and independently checks the closure certificate. The next enhancement is stable, cheapest sensor design. For ellipsoidal noise, test TᵀT≼γ²HᵀR⁻¹H with exact PSD or negative-quadratic-form witnesses. A finite-horizon target family and an all-time invariant-metric certificate are different contracts. Do not describe rank alone as robustness.

The first deployable result should accept a declared model, targets, sensors, costs and a noise cap, then return a minimal observer, an optimal finite-panel receipt or a concrete impossibility witness. General nonlinear and uncertain physical models require additional hypotheses, rather than inheriting the finite rational theorem automatically.

## Highest research ceiling: dynamic Hamiltonian cores in all degrees

For a polynomial H, set D={H,·} and C_j=T_(2j+1)(H,·). The exact dynamic core is the polynomial space annihilated by every C_jD^r. A polynomial-degree cutoff is unsafe because D may increase degree. Instead form ascending left ideals I_r=<C_jD^s:0≤s≤r> in the Weyl algebra Q[q,p]⟨∂q,∂p⟩. Noetherianity gives finite stabilization, and a stabilized ideal's polynomial common kernel is the full dynamic core.

The handoff supplies the proof of that abstract reduction and a normal-ordered exact operator checker. It does not supply a Gröbner discovery backend or a general polynomial-PDE solution classifier. A backend must export correction containment, generator provenance and right-D closure identities. All three are checked as operator identities, so the certificate has all-degree scope even though it is finite.

The first new classification target is the dynamic-core stratification of qp³ plus a general quadratic perturbation. One-step exactness is unchanged across that family; repeated dynamics are not. The retained results imply that qp³ has core Q[p]⊕qQ[p], while qp³+λq² has core span{1,H} for any nonzero rational λ. The parameter-zero jump is a calibration theorem, not a new priority claim. Complete new strata must identify every exceptional branch and justify each parameter division.

## A second general engine: primitives or obstruction witnesses

For a supplied finite rational cochain complex, construct i,p,h with Id−ip=dh+hd, pi=Id, di=0 and pd=0. For a cocycle b, pb=0 gives the explicit primitive hb. If pb≠0, a nonzero row of p supplies a dual functional vanishing on boundaries but not on b. This turns local-to-global and finite deformation recipes into a reusable exact operation.

The seed constructs and independently checks these identities over Q. The next extension is a finite differential graded Lie model whose Maurer–Cartan equations are solved order by order; a cohomology class then witnesses the first genuine obstruction. Integer Smith certificates are a separate backend. A rational contraction cannot erase integral torsion.

## Optional arithmetic extension with a complete global reduction

The general Pell programme takes D>0 nonsquare, N≠0 and a supplied integral norm-one unit ε=a+b√D>1. Its finite seed window is proved using the real embeddings: for N>0, x>0, y≥0 and y²<b²N; for N<0, x≥0, y>0 and Dy²<a²|N|. Exact square tests enumerate all representatives, and unit multiplication/inversion preserves integrality. The supplied unit need not be fundamental; the result concerns its generated orbits. This is a constructive completeness engine, not a claim to solve arbitrary Diophantine equations.
