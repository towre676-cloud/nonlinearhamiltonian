# The 2023 Mathematics Compendium

This package develops all 114 mathematics questions from the recovered 2023 retrospective. Every M entry includes definitions, a stated result, a derivation or proof, an explicit example, its limits and a further-development question. The S entries connect the subjects and develop additional restricted-family classifications and exact certificates. Classical material is not represented as a new discovery.

Open 2023_Mathematics_Compendium.html for the searchable edition or 2023_Mathematics_Compendium.pdf for the typeset edition. The original revised-question table is preserved as original_2023_table.html. Historical attribution remains fragmentary and is recorded by the original U, A and T labels; the package is not a complete export of the 2023 chats.

Run `python verify_all.py` with Python 3 to reproduce every supplied computational verifier. On Windows, VERIFY_WINDOWS.cmd tries the Python launcher and then python. These verifiers use only the Python standard library and do not need network access. The runner writes verification_summary.json and each chapter writes its own scoped check report. A proof-only record is explicitly distinguished from a passed executable check. The programs verify their declared examples and certificates, not every general theorem in the text.

The folders chapters/a through chapters/f preserve developed-entry records, portable verifiers, exact certificate data and independent review records. compendium.json is the integrated machine-readable text. coverage.csv maps the 114 original identifiers to their developed results. The root syntheses.json and verify_syntheses.py hold the connecting arguments and their example checks. Additional S treatments and their certificates are retained with their authoring chapter.

For optional document rebuilding, install reportlab and Pillow, then run `python build_compendium.py`. Regenerate the three scientific figures and CSV data with `python make_figures.py` after installing matplotlib. These optional build dependencies are not needed to read the documents or replay the mathematical verifiers. On Linux the PDF builder uses DejaVu fonts at their standard system path; adapt that path on another platform. The delivered PDF is already built.

The mathematical scope is deliberately explicit. An exact finite optimization certificate applies to its declared target family. A finite sequence cannot establish an infinite recurrence without a model-class bound. Reversible coordinate charts preserve information under the stated assumptions. The Gaudin classifications concern the specified one-magnon sector and do not constitute a general Langlands theorem. Remaining extensions are stated as extensions rather than silently counted as solved.
