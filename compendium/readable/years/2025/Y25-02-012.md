## Revised question retained in the annual source

How does optimizing a large parameter grid change the uncertainty of the selected score?

## Status

Developed mathematical result with explicit hypotheses and checked example; historical claims repaired where necessary

## Summary

A finite-family concentration bound quantifies selection error under explicit independent bounded-data assumptions. It shows why a best synthetic Sharpe value is not a validated predictive result.

## Definitions

LetK fixed candidate models have lossesℓ_k(Z)∈[0,1] on independent identically distributed validation observationsZ₁,…,Z_n.

WriteR_k=Eℓ_k andR̂_k=n⁻¹Σℓ_k(Z_i). The candidates must be fixed independently of this validation sample for the elementary bound.

The recovered gridj_min,j_max,λ₁,λ₂,Q and500-ms sampling describe a search procedure, not an independence or boundedness theorem for market returns.

## Result name

Uniform finite-family validation bound

## Result statement

With probability at least1−δ, every candidate satisfies|R̂_k−R_k|≤ε=√[log(2K/δ)/(2n)]. The empirically best candidate then has true risk at most2ε above the best candidate’s true risk.

## Proof

Hoeffding’s inequality givesP(|R̂_k−R_k|>ε)≤2e^{−2nε²} for each fixed candidate. A union bound overK candidates gives2Ke^{−2nε²}; setting this equal toδ gives the radius. Ifk̂ minimizes empirical risk andk* minimizes true risk, thenR_k̂≤R̂_k̂+ε≤R̂_k*+ε≤R_k*+2ε. This is a complete selection argument under the assumptions, not an assertion that arbitrary rolling returns satisfy them. Fitting candidates on the same validation sample violates the fixed-family premise unless the entire possible family was already included inK.

## Worked example: setup

TakeK=1000,n=1000,δ=0.05.

## Worked example: calculation

The radius is approximately0.07279 and the excess-risk bound approximately0.14558. Increasing the number of searched combinations without more independent observations enlarges the uniform uncertainty. A Sharpe ratio also needs a nonzero variance denominator; a constant positive synthetic return makes its naive ratio undefined or infinite rather than exceptionally certified.

## Worked example: conclusion

The revised optimization specifies an out-of-sample inferential guarantee and its limitations.

## Limits

Actual time series can be dependent, nonstationary and heavy-tailed. This result is not financial guidance and does not certify a strategy. Synthetic signals test implementation behavior, not historical market performance.

## Extension

Use a chronological training/validation/test split and an explicit dependence model. Derive a concentration or bootstrap procedure justified for that model and report the complete search family, costs and uncertainty of the final score. Reusing the validation sample adaptively changes the inference problem. A final untouched test set can evaluate the selected model after selection, but its confidence statement then concerns that fixed selected model, not a fresh search over the test data. Repeatedly checking and selecting on the final set destroys this separation.
