## Summary

The recovered higher-gauge discussion namesH²(BG,U1). A projective representation of a finite group gives a fully calculable example of the relevant cocycle identity. It also exhibits a nontrivial class without claiming a full cohomology classification.

## Definitions

LetG=F2² with addition. Forv=(a,b), setU_v=X^aZ^b using PauliX,Z, which satisfyZX=−XZ.

A normalized2-cocycleω satisfiesω(v,w)ω(v+w,u)=ω(w,u)ω(v,w+u) andω(0,v)=ω(v,0)=1.

## Result name

An explicit nontrivial multiplier

## Result statement

U_vU_w=ω(v,w)U_(v+w), whereω((a,b),(c,d))=(−1)^(bc). This is a normalized2-cocycle and is not a coboundary.

## Proof

MoveZ^b pastX^c to obtain the sign(−1)^(bc); exponents add modulo2 becauseX²=Z²=I. The cocycle identity compares exponentsbc+(b+d)e withde+b(c+e), equal modulo2, so associativity is exact. A coboundary on an abelian group has formf(v)f(w)/f(v+w) and is symmetric inv,w. But forv=(1,0),w=(0,1), ω(v,w)=1 andω(w,v)=−1. Hence this cocycle cannot be a coboundary. This elementary obstruction proves a nonzero cohomology class in the specified convention.

## Limits

The extension built from these particular Pauli lifts is not automatically the quaternion groupQ8; the squares of lifts and coefficient subgroup matter. The result is not a computation for everyG.
