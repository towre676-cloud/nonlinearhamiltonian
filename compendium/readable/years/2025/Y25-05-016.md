## Revised question retained in the annual source

Reconstruction: What simple context model really satisfies a gluing theorem, and which data are missing from the proposed fibred or sheaf semantics?

## Status

## Summary

The source’s categorical expansion is truncated after its fibred-category claim. A context poset, compatible operations and a collapse symbol do not alone define a sheaf or fibration. A finite observation-domain model supplies a genuine gluing statement while making the missing morphisms visible.

## Definitions

Fix a finite set Ω. Contexts are subsets U⊆Ω, ordered by inclusion. Define F(U)=Q^U, the rational-valued functions on U.

For V⊆U, restriction res^U_V sends f to f|_V. A cover of U is a family U_i with union U. Compatibility means equal restrictions on every overlap U_i∩U_j.

## Result name

A concrete sheaf of contextual values

## Result statement

Every compatible family f_i∈F(U_i) glues to a unique f∈F(U). Restrictions preserve pointwise addition and multiplication. Thus this model has exact contextual algebra without replacing equality by numerical tolerance.

## Proof

Define f(ω)=f_i(ω) using any i withω∈U_i. Compatibility on overlaps makes the value independent of the choice. Each restriction equals the prescribed f_i. If another function has those same restrictions, its value at anyω is fixed by one covering set, proving uniqueness. Restriction identities res^U_U=id and res^V_W∘res^U_V=res^U_W follow directly from evaluating functions. Pointwise arithmetic commutes with restriction because both sides evaluate to the same rational sum or product. These are actual maps and equations; they are the data absent from a bare statement that contexts compose by a semilattice join.

## Worked example: setup

Take Ω={a,b,c}, U₁={a,b}, U₂={b,c}, with f₁(a)=1,f₁(b)=2 and f₂(b)=2,f₂(c)=3.

## Worked example: calculation

The unique glued function is(1,2,3). Changing f₂(b) to5 destroys compatibility, and no global function can have both restrictions. Pointwise functions form a product ring Q³, not a field: the nonzero functions(1,0,0) and(0,1,0) multiply to zero. The verifier checks gluing and this zero-divisor certificate exactly.

## Worked example: conclusion

A genuine categorical context model can preserve local arithmetic while still lacking a global field structure.

## Limits
