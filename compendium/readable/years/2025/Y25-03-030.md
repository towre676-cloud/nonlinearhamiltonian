## Revised question retained in the annual source

What explicit example distinguishes a homotopy fiber from an ordinary set-theoretic fiber?

## Status

Developed classical result with a checked example; recovered claims corrected where needed

## Summary

The recovered HoTT discussion lists homotopy fibers without a defined map. The inclusion of a base point into the circle gives a simple exact example in which path data radically changes the answer. It is a classical topology model, not a formalization of an unspecified type theory.

## Definitions

Takef:{*}→S1 withf(*)=1. The ordinary fiber over1 is a single point.

The homotopy fiber consists of(*,γ), whereγ is a path fromf(*) to1; here it is the based loop spaceΩS1.

## Result name

An exact component classification

## Result statement

π0(ΩS1)≅Z by winding number; each component is contractible. Thus the homotopy fiber has infinitely many components despite the one-point ordinary fiber.

## Proof

Use the coveringp:R→S1,p(t)=e^(2πit). Every based loop has a unique lift starting at0, whose endpoint is an integern becausep sends allintegers to1. That integer is invariant under based homotopy by continuity and the discrete endpoint set. Conversely, two lifted paths with the same endpoints are linearly homotopic inR while fixing endpoints; projection gives a based homotopy. Within a fixedn, the lifted path space is contractible by straight-line contraction to the path t↦nt. This proves both the integer classification and the componentwise contractibility. The ordinary preimage never records these paths.

## Worked example: calculation

Their lift endpoints are0 and1. Both lie over the same source point, but they are in different homotopy-fiber components. The difference is path information rather than a numerical cardinality attached to the original set.

## Worked example: conclusion

A homotopy construction has concrete extra data that must be stated, not inferred from a higher-category label.

## Limits

General homotopy fibers require a topological or∞-categorical model and appropriate equivalences. The example does not prove newHoTT coherence rules or reconstruct a missing categorical map.

## Extension

Specify the actual map and base point, then compute its long exact homotopy sequence or a model of the fiber before assigning an invariant.
