## Summary

The August31 CRO response asserted equivalence between a runtime residue and vanishing H¹ while retaining stubs. A minimal cochain example rejects that equivalence. A separate decay-rate bound shows what the surviving logarithmic diagnostic can legitimately certify.

## Definitions

For a finite cochain complex, H¹=kerδ¹/imδ⁰. In an inner-product complex the Hodge Laplacian is L₁=δ⁰δ⁰*+δ¹*δ¹. For positive observed energy set αhat=−(logE_k−logE_{k−1})/Δt.

## Result name

Residual scope and logarithmic sensitivity

## Result statement

A zero Laplacian residual can occur for a nonzero H¹ class. If E_k=e^(−αt_k+η_k) with|η_k|≤ε, then|αhat−α|≤2ε/Δt. A hash ledger certifies neither cohomology nor the truth of its logged claims.

## Proof

Take C⁰=C¹=R,C²=0 andδ⁰=δ¹=0. Then H¹=R and L₁=0, so every vector has zero Laplacian residual although cohomology is nonzero. More generally Hodge theory identifies kerL₁ with cohomology, so a nonzero harmonic vector is precisely the wrong witness for global vanishing. For the rate bound, substitute the noisy log energy:αhat=α−(η_k−η_{k−1})/Δt and apply the triangle inequality. Smaller time steps amplify bounded log noise. Finally a finite digest records a function of bytes; correctness of the bytes’ mathematical assertion is a separate predicate and is not implied by digest equality.
