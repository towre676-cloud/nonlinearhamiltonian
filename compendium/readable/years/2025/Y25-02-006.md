## Revised question retained in the annual source

What can the simplifiedg′=−2A,A′=−κA prototype establish before full geometric evolution terms are supplied?

## Status

Developed mathematical result with explicit hypotheses and checked example; historical claims repaired where necessary

## Summary

The stated prototype is exactly solvable and gives a parameter-dependent positivity condition. This provides a useful code reference while exposing why damping one variable does not automatically preserve a metric.

## Definitions

For scalar components takeA′=−κA,g′=−2A withκ>0 and initial valuesA₀,g₀.

A positive scalar metric component requiresg(t)>0; positive definiteness of a full matrix is a stronger joint condition.

Curvature, constraints, gauge equations and boundary conditions are not included in this two-variable model.

## Result name

Exact damped-source evolution

## Result statement

A(t)=A₀e^{−κt} andg(t)=g₀−(2A₀/κ)(1−e^{−κt}). ForA₀>0,g stays strictly positive for all finite times ifg₀≥2A₀/κ, with a positive uniform lower bound only when the inequality is strict.

## Proof

The first equation solves by separation. Integratingg′ using that solution gives the displayed expression. IfA₀>0,g is decreasing and has limitg∞=g₀−2A₀/κ. A strictly positive limit gives uniform positivity. At equalityg(t)=g₀e^{−κt}>0 for finite time but tends to zero, so uniform coercivity fails. If the limit is negative, continuity forces a finite zero crossing. Solvingg=0 givese^{−κt}=1−κg₀/(2A₀) when0<g₀<2A₀/κ. This is a complete exact diagnostic for the simplified system, independent of any GPU implementation.

## Worked example: setup

Useκ=1/10,A₀=1/10,g₀=1.

## Worked example: calculation

ThenA=(1/10)e^{−t/10} andg=2e^{−t/10}−1. The component reaches zero att=10log2 despite the sourceA decaying. Usingg₀=3 instead givesg=1+2e^{−t/10}, uniformly bounded below by one.

## Worked example: conclusion

An analytic reference trajectory can test a numerical RHS while keeping its geometric interpretation conditional.

## Limits

The source explicitly labels the CUDA prototype simplified. Passing this ODE check proves neither the BSSN constraints nor stable Einstein evolution; omitted Christoffel/Ricci terms cannot be treated as validated placeholders.

## Extension

For a full symmetric matrixg, derive an eigenvalue lower bound from an operator-norm integral estimate onA. Then test constraint propagation and convergence for a declared complete system and exact geometric benchmark. At κ=0 the solution is A=A₀ and g=g₀−2A₀t, obtained either directly or as the continuous κ→0 limit on every bounded time interval. Substituting κ=0 into a formula containing 1/κ without taking that limit would create a spurious singularity. Zero damping is a distinct parameter case.
