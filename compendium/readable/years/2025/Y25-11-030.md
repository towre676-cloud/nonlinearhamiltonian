## Summary

The recovered passage invoked Pontryagin, HJB, Riccatiand broad system viability. A scalar linear-quadratic control problem provides a complete finite-horizon theorem with no unstated economic or geometric interpretation.

## Definitions

Letx′=u, x(0)=x₀, and minimize J=(1/2)∫₀ᵀ(qx²+ru²)dtwithq, r>0and no terminal cost.

Set P(t)=√(qr)tanh(√(q/r)(T−t)).

## Result name

Exact value and optimal feedback

## Result statement

The minimum is V(0, x₀)=P(0)x₀²/2, and the unique optimal control satisfiesu=−P(t)x/r. The function Pobeys P′=P²/r−qwith P(T)=0.

## Proof

Differentiate the displayedhyperbolictangentto verify the Riccatiequation and terminal condition. For any admissible control, d(Px²/2)/dt=P′x²/2+Pxu. Add this derivative to the running cost and substitute P′=P²/r−q; the result is(r/2)(u+Px/r)². Integrating and using P(T)=0gives J=P(0)x₀²/2+(r/2)∫(u+Px/r)²dt. The nonnegative remainder proves the lower bound, and the feedback equation makes itzero. The feedback ODE has a unique solution because P is continuous, so the optimum is attained and unique up to almost-everywhere equality. This also derives the quadratic HJB ansatz rather than merely asserting it.

## Worked example: setup

## Worked example: calculation

P(0)=tanh1, so the optimal cost is(tanh1)x₀²/2. The feedback weakens tozeroas t→Tbecause there is no terminal penalty. In the infinite-horizon limit P→1and the feedback tends tou=−x, the familiar stable closed loop.

## Worked example: conclusion

The control theorem has exact hypotheses, an explicit solution, and a proof by completing squares.
