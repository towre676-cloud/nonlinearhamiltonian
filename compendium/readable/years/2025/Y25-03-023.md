## Summary

The recovered Langevin reference does not specify a kernel or noise law. A two-variable linear system gives an exact reduction. It proves that a memory term and a source depending on the hidden initial condition arise together; dropping the source changes the model.

## Definitions

Letx′=−ax+by andy′=−cy+dx, withreal coefficients andc>0.

Initial data arex(0)=x0,y(0)=y0. A memory kernel acts by convolution over pastx.

## Result name

Exact reduced Volterra equation

## Result statement

The observed coordinate satisfies x′(t)=−ax(t)+b e^(−ct)y0+bd∫₀ᵗe^(−c(t−s))x(s)ds. This is equivalent to the full system with the stated initial data.

## Proof

Multiply the second equation bye^(ct) and integrate to obtainy(t)=e^(−ct)y0+d∫₀ᵗe^(−c(t−s))x(s)ds. Substitute into the first equation to get the reduced formula. Conversely, given a solutionx of that Volterra equation, definey by the integral expression; differentiating recoversy′=−cy+dx and thenx′=−ax+by. The initial values also agree. Thus the reduction is exact, with no assumption that the hidden coordinate is random. Ify0 is random, the decaying source inherits its law, and a fluctuation–dissipation identity requires additional equilibrium assumptions rather than following from the elimination alone.

## Worked example: setup

Takea=0,b=1,c=1,d=−1,x0=1,y0=0.

## Worked example: calculation

The full matrix has characteristic polynomialλ²+λ+1. Hencex(t)=e^(−t/2)[cos(√3t/2)+(1/√3)sin(√3t/2)]. It obeysx′(0)=0 andx″+x′+x=0. The Volterra form isx′=−∫₀ᵗe^(−(t−s))x(s)ds, which differentiates to that same equation.

## Worked example: conclusion

The memory kernel is derived and independently checkable, with its sign fixed by the hidden coupling.

## Limits

This deterministic model is not a stochastic thermostat or a proof of a resonance phenomenon. Infinite reservoirs require convergence and a specified initial-state distribution.

## Extension

For a block matrix or self-adjoint Hamiltonian, repeat the variation-of-constants argument and bound the kernel norm. State the hidden initial condition before interpreting reduced dissipation.
