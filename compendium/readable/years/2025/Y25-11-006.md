## Revised question retained in the annual source

Can an exact differential carry the claimed nonzero winding periods and entropy?

## Status

Classical or newly chosen explicit model developed with proof; historical conjectures delimited

## Summary

The recovered model simultaneously declared Jconstant, defined χ=(e/N)d J, and assigned nonzero quantized integrals. These statements are incompatible. A genuine circle one-form gives a constructive replacement and makes clear what hash entropy would mean mathematically.

## Definitions

Let N>0 and J be a single-valued smooth real function; χ=(e/N)d J is exact.

On S¹ the angular differentiald θ is a global closed one-form even though θ is only locally a single-valued real function.

## Result name

Period obstruction and a correct circle model

## Result statement

Every closed-loop integral of χ is zero. In contrast η=(N/(2π e))d θ has period∫_γη=n N/e for a loop of windingn. The expressionlog(N/e)=1 holds only when N=e², not for arbitrary N.

## Proof

For a parametrized closed loop γ, the chain rule gives∫_γ d J=J(γ(1))−J(γ(0))=0. If Jis constant, χ vanishes pointwise, making the contradiction stronger. For the circle model lift γ to an angle Θ(t) on an interval. Its endpoint difference is2π n, so the integral of η is Nn/e. There is no globally single-valued real Jwithd J=d θ, because such a function would force the nonzero circle period to vanish. Finallylog(N/e)=log N−1, so setting it equal toone fixes N=e². If N denotes the number of independent uniform hash bits, Shannon entropy is Nlog2 nats, whereaslog N is the entropy of N equiprobable outcomes; these are different sample spaces.

## Worked example: conclusion

Winding can be modeled consistently, but it requires a non-exact cohomology class and a clearly specified probability space.

## Limits

No cryptographic deck transformation or physical energy quantization follows from these definitions. A hash digest is finite discrete data and does not automatically define a smooth covering-space action.
