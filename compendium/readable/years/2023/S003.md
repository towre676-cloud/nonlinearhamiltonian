## Status

Classical framework with a proved synthesis and worked example

## Summary

The common core of exact classification, graph signatures and probe selection is the partition induced by the available observations. On a finite state set, that partition has a complete algebraic description. This is stronger and more precise than assigning a complexity score to each state.

## Definitions

Let Ω be a finite set and f₁,…,f_m:Ω→R be exact observations, with m≥1. States x and y are equivalent when f_i(x)=f_i(y) for every i.

Let A be the unital algebra generated by the f_i under real linear combinations and pointwise products. Its elements are polynomial functions of the observation vector.

## Result name

The observation algebra is exactly the set of functions constant on observation classes

## Result statement

If the observations induce K distinct classes, then A has dimension K and contains the indicator of each class. If every observation is invariant under a group action, no function in A can distinguish two states in the same orbit.

## Proof

Every polynomial in the observations is constant on each equivalence class, giving one inclusion. For the reverse inclusion choose a linear combination h=Σa_i f_i whose values h₁,…,h_K on the classes are all distinct. Such coefficients exist because equality on any two distinct observation vectors excludes only one proper hyperplane, and finitely many proper hyperplanes cannot cover R^m. The Lagrange polynomial ℓ_j(h)=∏_(k≠j)(h−h_k)/(h_j−h_k) is the indicator of class j. These K indicators span every function constant on the classes and are independent. This also gives a constructive integer choice: take a_i=T^(i−1). Each pairwise equality is a nonzero polynomial in T of degree at most m−1, so among more than (m−1)K(K−1)/2 distinct integers at least one choice avoids all equalities. Group invariance is preserved by sums and products, proving the orbit obstruction.

## Worked example: setup

Take Ω={(0,0),(1,0),(0,1),(1,1)} and first observe f(x,y)=x+y.

## Worked example: calculation

The observed values 0,1,1,2 give K=3 classes. Swapping coordinates preserves f, so no polynomial in f can separate (1,0) from (0,1). Add g(x,y)=x. The combined observation separates all four states; h=f+2g takes values 0,3,1,4. Its four Lagrange polynomials recover the four individual state indicators exactly. The verification script checks the indicator table using rational arithmetic.

## Worked example: conclusion

An ambiguity caused by the observation partition cannot be repaired by increasingly elaborate postprocessing of the same data. A new probe must split the ambiguous class.

## Limits

The finite-set hypothesis is essential to this elementary algebraic completeness statement. Exact equality, noisy equality and approximate separability are different questions. A coordinate identity or formal feature space may include states that no physical object realizes.

## Extension

For a specified family of admissible probes, define each probe’s covered pairs as those it separates. Minimum-cost separation of a finite target set becomes a weighted set-cover problem on state pairs. The certificate is exact only for that declared target population; it makes no automatic claim about unseen states or faults.
