## Status

Classical framework with a proved synthesis and worked example

## Summary

A finite-state linear description and a recurrence for an observed sequence are two presentations of the same algebraic structure. The useful dimension is the reachable and observable dimension, which can be smaller than the dimension of the original matrix. This links the Cayley–Hamilton, observability, Fourier and exact-certificate questions without claiming that every nonlinear model has finite closure.

## Definitions

Work over a field F. A scalar sequence has a linear representation y_n=cAⁿb with finite-dimensional A, row c and column b. Its infinite Hankel matrix is H=(y_(i+j)) for i,j≥0.

The rank of the infinite Hankel matrix is the supremum of ranks of its finite submatrices. A recurrence of order r means y_(n+r)=Σ_(j=0)^(r−1)a_j y_(n+j) for every n≥0.

## Result name

Hankel rank equals the minimum linear realization dimension

## Result statement

For a scalar sequence with a finite linear representation, the minimum possible state dimension equals rank H. It also equals the minimum order of an everywhere-valid forward recurrence, with the zero sequence assigned order zero.

## Proof

For any representation H factors as O R, where O has rows cAⁱ and R has columns Aʲb. Therefore rank H cannot exceed the state dimension. Restrict first to the reachable subspace span{Aʲb}, then quotient by its invisible subspace {v:cAⁱv=0 for all i}. The resulting representation is reachable and observable. In a minimal r-dimensional scalar realization, the first r Krylov columns are independent: the first linear dependence would make their earlier span A-invariant and stop further growth. The analogous statement holds for the first r observation rows. Their product is the leading r×r Hankel block, which is consequently invertible, proving rank H≥r. Cayley–Hamilton gives a recurrence of order at most r. Conversely, an order-r recurrence has an r-dimensional companion realization, so no smaller recurrence is possible. These arguments also account for finite transients, which can contribute nilpotent modes.

## Worked example: setup

Take y_n=2ⁿ+3ⁿ, generated by A=diag(2,3), b=(1,1)ᵀ and c=(1,1).

## Worked example: calculation

The first values are 2,5,13,35,97. The leading 2×2 Hankel matrix is [[2,5],[5,13]], whose determinant is 1. The polynomial (z−2)(z−3)=z²−5z+6 gives y_(n+2)=5y_(n+1)−6y_n. Thus a two-state representation exists and the nonzero Hankel determinant rules out a one-state representation. If instead A=diag(2,−2), then y_n=2ⁿ+(−2)ⁿ has dimension two, while the even subsequence y_(2k)=2·4ᵏ has dimension one.

## Worked example: conclusion

A short recurrence can be a certificate of exact observable compression. Subsampling can also erase modes, so reduced apparent dimension need not mean that the original dynamics became simpler.

## Limits

Finite prefix agreement alone never proves an infinite recurrence without a model-class or order bound. Given any inspected prefix, a sequence that agrees there and changes later is indistinguishable on that prefix. Numerical Hankel rank additionally requires tolerances and perturbation analysis.

## Extension

Given an exact matrix family A(θ), determine where the reachable-observable dimension changes by computing rank minors. This is a finite algebraic question for a specified polynomial parameterization. For nonlinear polynomial dynamics, the degree-growth obstruction in M018 identifies an important class where a polynomial closure containing the state coordinate cannot be finite.
