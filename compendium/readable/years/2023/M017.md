## Revised question retained in the annual source

Which states can inputs reach, which states outputs distinguish, and what is the smallest realization preserving the input-output map?

## Status

Minimal zero-initial-state quotient constructed

## Summary

Reachability and observability answer different questions. Their intersection structure determines which internal modes affect driven input-output behavior from zero initial state. A mode can be unstable and entirely absent from the transfer function, making the initial-condition convention essential.

## Definitions

For a finite-dimensional real or complex system ẋ=Ax+Bu and y=Cx+Du with locally integrable inputs, define R=span{A^k imB:k≥0}, the reachable subspace.

Let N=∩_(k≥0)ker(CA^k), the unobservable subspace.

Both R and N are A-invariant, and the transfer function is H(s)=C(sI−A)^(−1)B+D where the resolvent exists.

## Result name

The zero-initial input-output state lives on R/(R∩N)

## Result statement

Restriction to R discards modes no input can excite from zero. Quotienting by R∩N then discards modes no output can detect. The resulting realization is reachable and observable and has the same zero-initial input-output map; its dimension is the standard minimal realization order.

## Proof

Starting at zero, the variation-of-constants formula x(t)=∫_0^t e^(A(t−s))Bu(s)ds lies in R because that subspace is A-invariant and contains imB. Adding a state in R∩N never changes any subsequent output, including under common future inputs, so the quotient preserves the response. Conversely, all reachable quotient states are generated by the projected input, and an invisible quotient class would have a representative in N, hence in R∩N, so it is zero. These properties characterize the usual minimal finite-dimensional realization. Replacing the zero initial condition by arbitrary initial states changes the target: visible but unreachable modes can now contribute.

## Worked example: setup

Take A=diag(−1,−2,3), B=(1,0,1)^T and C=(1,1,0).

## Worked example: calculation

R=span(e1,e3), while N=span(e3). The minimal driven state therefore has dimension one and transfer function 1/(s+1). The internally unstable e3 mode is reachable but invisible. The e2 mode is visible but unreachable; it matters for initial condition e2, producing e^(−2t), but not for zero-initial driven responses.

## Worked example: conclusion

The example has reachable rank two and observable rank two, yet minimal driven order one. Merely taking either rank misses the intersection.

## Limits

A stable transfer function does not establish internal stability when an unstable canceled mode remains. No empirical sensor claim follows without a correct state and observation model.
