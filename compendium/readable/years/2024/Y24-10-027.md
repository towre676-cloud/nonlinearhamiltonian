## Revised question retained in the annual source

How do quantifier order and capture-avoiding substitution affect a formal mathematical statement?

## Status

Classical result; recovered proposal repaired

## Summary

The recovered logic examples become rigorous after specifying a domain and interpretation. Quantifier order is not a stylistic choice: it can distinguish a uniform witness from a witness that depends on the input. Variable substitution must also avoid changing which variables are bound.

## Definitions

∀x∃yR(x,y) permitsy to depend onx; ∃y∀xR(x,y) requires one witness for allx.

A free occurrence of a variable is not governed by a quantifier for that variable. Substitution replaces free occurrences only, with bound variables renamed if needed.

## Result name

An exact two-element countermodel

## Result statement

OnD={0,1} withR(x,y) meaningx=y, ∀x∃yR(x,y) is true and∃y∀xR(x,y) is false. Thus the two quantifier orders are not logically equivalent.

## Proof

For eachx choosey=x, proving the first formula. For any fixedy∈D choosex=1−y; thenx≠y, so the universal condition fails and the second formula is false. The reverse implication is valid in every nonempty domain: one uniform witness also serves each individualx. For binding, considerφ(x)=∃y(x≠y). Substituting a free variabley forx cannot produce∃y(y≠y), because that would capture the newly inserted occurrence. First rename the bound variable toz, giving∃z(x≠z), then substitute to obtain∃z(y≠z). The latter retains the intended dependence on the free value ofy.

## Worked example: calculation

The correctly substituted formula∃z(y≠z) is true for either free valuey, by choosing the other element. The captured formula∃y(y≠y) is false. Thus a syntactic substitution mistake can reverse truth even in the smallest nontrivial model.

## Worked example: conclusion

Quantifier scope and binding are part of the mathematical claim, and finite countermodels can expose an invalid rewrite immediately.

## Limits

Empty-domain conventions can affect some quantifier laws, so standard first-order logic usually assumes a nonempty domain. Natural-language subject–verb–object order does not by itself determine quantifier scope.

## Extension

For a formal-language project, assign every relation an arity, every term a type and every quantifier an explicit scope. Implement alpha-renaming and free-variable checks before attempting automated derivations.
