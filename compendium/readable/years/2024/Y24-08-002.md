## Revised question retained in the annual source

Which self-adjoint operator is defined, and what exact relation connects its spectrum to the object being studied?

## Status

Revised classical development with scoped worked result

## Summary

A finite graph provides a fully defined Dirac-type operator whose spectral gap and homological kernel can be proved exactly. It illustrates legitimate spectral topology without claiming that an arbitrary operator realizes the zeros of an L-function. The latter correspondence would require a separate theorem covering every relevant zero.

## Definitions

For an oriented finite graph, let B:C₀→C₁ be its incidence matrix over R. On C₀⊕C₁ define D=[[0,Bᵀ],[B,0]]. It is symmetric, and D²=diag(BᵀB,BBᵀ). Nonzero singular values of B generate paired eigenvalues±σ of D.

## Result name

The complete path-three Dirac spectrum

## Result statement

For the path with three vertices and two edges, B=[[-1,1,0],[0,−1,1]]. The resulting five-by-five D has spectrum{0,±1,±√3}, so its smallest positive absolute eigenvalue is1. Its kernel dimension is one.

## Proof

The two-by-two edge Laplacian BBᵀ=[[2,−1],[−1,2]] has eigenvalues1 and3, with independent eigenvectors(1,1) and(1,−1). Each nonzero singular mode produces a pair of D eigenvectors by solving Bv=σw and Bᵀw=σv. The vertex Laplacian has the additional constant null vector(1,1,1), while Bᵀ has no nonzero edge null vector. This supplies all five independent modes. Equivalently D(D²−I)(D²−3I)=0, which the verifier checks by exact integer matrix multiplication.

## Worked example: setup

Orient both edges in the same direction and reverse one orientation.

## Worked example: calculation

Reversing an edge multiplies one row of B by−1. The full D is conjugated by an orthogonal sign matrix on its edge component, preserving its spectrum and gap. This is an actual operator equivalence. Merely matching a numerical gap with an unrelated zero spacing would not give such an intertwiner.

## Worked example: conclusion

The gap, kernel and orientation invariance follow from a stated finite operator, with no speculative arithmetic identification.

## Limits

A continuous Dirac operator needs a manifold, metric, spin or Clifford structure and operator domain. A graph gap does not prove a Riemann hypothesis or determine all persistence intervals.

## Extension

Specify a weighted graph family, track singular values under perturbation and determine which observation maps preserve the operator’s kernel and low-frequency modes.
