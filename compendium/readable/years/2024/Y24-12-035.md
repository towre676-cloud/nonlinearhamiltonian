## Revised question retained in the annual source

What does the standard toric code prove about local errors, and what would a proposed extension have to improve?

## Status

Developed classical result with a checked example; historical claims corrected where needed

## Summary

The historical claim of going beyond toric code needs a baseline with a defined lattice, code space, and error model. The square torus code has exact commuting stabilizers and nonlocal logical operators; these properties can be proved at the Pauli-algebra level.

## Definitions

Place one qubit on every edge of an L×L square lattice with periodic boundaries,L≥3.

For a vertexv setA_v=∏_{e incident v}X_e; for a plaquettep setB_p=∏_{e∈∂p}Z_e.

## Result name

Commuting stabilizers and distanceL

## Result statement

AllA_v andB_p commute. Their common+1eigenspace encodes two qubits, and a shortest noncontractible Pauli loop has lengthL, giving code distanceL.

## Proof

X andZ anticommute on one edge. A star and plaquette share either zero or two edges, so their commutation sign is(+1)or(−1)²=+1. Products of all stars and all plaquettes each equalI because every edge occurs twice. On the connected torus these are the only independent relations of each type; thus the stabilizer rank is2L²−2 among2L²qubits and the code dimension is2². AZ string anticommutes with stars at its endpoints, detecting open-string errors; a closed string commutes with all stars. Contractible loops are products of plaquettes and act trivially on the code. A noncontractible loop cannot be such a boundary and acts logically. The shortest noncontractible direct or dual cycle hasLedges, yielding the minimum nontrivial logical Pauli weightL.

## Worked example: setup

TakeL=3 and follow a Z string along one periodic row.

## Worked example: calculation

There are18edge qubits,9stars,and9plaquettes,with16independent stabilizers and a four-dimensional code space. A one-edgeZerror creates two violated star syndromes; a length-three wrappedZloop has no syndrome but changes a logical state. Thus local detectability and logical vulnerability coexist exactly as the distance statement predicts.

## Worked example: conclusion

The baseline protection is a precise code-space statement against bounded-weight Pauli errors, not an unrestricted immunity claim.

## Limits

This does not prove passive self-correction at nonzero temperature, nor protection against arbitrary correlated errors. The MPPF proposal had no recovered code, stabilizers, or distance certificate with which to establish an improvement.

## Extension

For a claimed extension, provide its commuting constraints or alternative code definition, count independent logical degrees of freedom, and exhibit both a lower bound and a matching logical operator for its distance.
