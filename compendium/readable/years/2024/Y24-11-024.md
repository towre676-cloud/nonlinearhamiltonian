## Revised question retained in the annual source

What can entanglement, superselection, and error correction each prove in a finite Hilbert space?

## Status

## Summary

The recovered catalogue named these concepts together but they express different mathematical constraints. A finite construction gives one theorem for each and shows why the error set and observable algebra must always be specified.

## Definitions

For a pure bipartite vector, the Schmidt coefficients are singular values of its coefficient matrix.

A superselection algebra acting block-diagonally on H=H₀⊕H₁ has no matrix elements between the sectors.

## Result name

Finite Schmidt and error-correction checks

## Result statement

A bipartite pure state has reduced eigenvalues equal to the squares of its Schmidt coefficients. The repetition code span{|000⟩,|111⟩} corrects the error set {I,X₁,X₂,X₃}, but not that set enlarged by Z₁.

## Proof

Write the state coefficient matrix C and use its singular value decomposition C=UΣV*. This gives orthonormal Schmidt vectors, and partial tracing yields UΣ²U*, proving the reduced spectrum. For the code projector P and two errors E_a,E_b in the displayed bit-flip set, P E_a*E_b P is P if a=b and zero otherwise: a nontrivial product flips one or two bits and maps either codeword outside the code. Thus the Knill–Laflamme scalar condition holds. But PZ₁P has diagonal entries 1 and −1 in the logical basis, not a scalar multiple of P, so a phase error is not correctable by this code. Finally if A=A₀⊕A₁, then ⟨ψ₀,Aψ₁⟩=0 for sector vectors simply by orthogonality; this is an algebra restriction, not a statement that all possible coherent superpositions cease to exist mathematically.

## Worked example: setup

Use the Bell state (|00⟩+|11⟩)/√2 and the repetition code above.

## Worked example: calculation

The Bell reduced density is I/2 and its entropy is log 2. The four bit-flip syndrome subspaces are pairwise orthogonal, permitting recovery. Yet a Z₁ error changes the relative logical phase and stays inside the code space, so a bit-flip syndrome alone cannot detect it.

## Worked example: conclusion

The three notions are linked only through explicitly defined states, observables, and errors; none implies all the others.

## Limits

No continuum quantum field theory or experimentally protected implementation follows. The Bell entropy uses the natural logarithm; it is one bit if logarithm base two is chosen.

## Extension

For a proposed physical noise model, compress every E_a*E_b to the code and check the scalar condition before claiming correction or topological protection.
