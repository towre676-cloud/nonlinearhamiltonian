## Revised question retained in the annual source

Is the arithmetic certificate a witness, a bounded census or an exhaustive global equivalence?

## Status

Classical mathematics with newly authored derivation or explicitly defined worked model

## Summary

The QF_NIA discussion connected arithmetic reductions to finite logical replacements. These are three different levels of conclusion. Exact substitution proves a witness immediately; replacing an unbounded equation by a finite disjunction additionally requires a proved global coverage argument.

## Definitions

For an integer equation E(n,m), a bounded census lists all solutions with n in a declared finite domain. A global census must cover every integer allowed by the original domain.

A proposed replacement E(n,m)⇔∨_((a,b)∈S)(n=a and m=b) is exact only when S is a complete solution set on that same domain.

## Result name

A finite SMT replacement needs a completeness theorem, while a single exact witness already proves satisfiability

## Result statement

Exact verification of every listed pair proves only the forward witness property of S. The reverse implication from an arbitrary solution to membership in S requires an additional completeness certificate. Congruence obstructions can, however, prove a global empty set directly.

## Proof

The finite disjunction implies E by substituting each pair and checking its equality. For the converse, one needs a theorem bounding all variables or an exhaustive descent/parametrization argument that reduces every solution to a verified case. A finite search limit alone supplies neither. For a congruence proof, reducing E modulo q is valid for every integer solution; if no residue pair satisfies it, the original equation has none, without a size bound.
