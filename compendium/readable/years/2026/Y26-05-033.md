## Revised question retained in the annual source

Reconstruction: When does factor inclusion define a complete closure rule, and why are maximal cliques only a pairwise consistency model?

## Status

Classical result or newly stipulated finite model; historical claims explicitly delimited

## Summary

The source’s CU kernel uses prime-factor sets, approved-grounded factors and maximal-clique worlds. These can be formalized exactly as a finite support calculus, but a graph cannot encode arbitrary higher-order contradictions. We prove both the constructive inclusion rule and its limitation.

## Definitions

Fix a finite set of distinct primes P. For squarefree integers A supported on P, let Pf(A) be its prime-factor set. Define A⊢B when Pf(B)⊆Pf(A).

For required support R, repair the current support S by cl_R(S)=S∪R. In a compatibility graph, a clique is a set with every pair compatible; maximal means no further vertex can be added while retaining that property.

## Result name

Prime-factor closure is a Boolean lattice, while pairwise compatibility need not imply joint consistency

## Result statement

Factor entailment is reflexive and transitive, and cl_R is extensive, monotone and idempotent. The minimal missing-factor repair is ∏_{p∈R∖S}p. Nevertheless a maximal clique is not a general certificate of simultaneous satisfiability.

## Proof

The entailment properties are immediate from set inclusion. Union with a fixed set is extensive and monotone; applying it twice gives(S∪R)∪R=S∪R, proving idempotence. Any repaired support containing S and R must contain their union, so the listed repair adds precisely the necessary absent primes. A separate approved-grounded set G⊆S changes admissibility to R⊆G and may require evidential repair even when asserted support already contains R. For the graph limitation, take three Boolean constraints x=0, y=0 and x∨y=1. Every pair has a satisfying assignment, so the compatibility graph is a triangle and its full vertex set is a maximal clique. All three together are inconsistent. Thus pairwise compatibility is insufficient for arbitrary logic unless an additional theorem proves a Helly-type or pairwise-to-global property for the chosen constraint family.

## Worked example: setup

Let S={2,3}, R={3,5} and approved support G={2}.

## Worked example: calculation

The semantic repair is factor5, giving squarefree product30. The evidential missing set is{3,5}, which differs because3 is asserted but not approved-grounded. For the Boolean triple, assignments(0,1),(1,0),(0,0) witness the appropriate pairwise satisfiabilities, but no single assignment meets all three.

## Worked example: conclusion

The factor model has a complete finite closure theorem and a precise graph-model boundary.

## Limits

Prime labels encode support only; they do not turn a proposition into a proof. A maximal clique is a maximal pairwise-compatible world, not automatically a logically complete or jointly realizable theory.

## Extension

Replace the compatibility graph by a conflict hypergraph or an actual SAT theory, and prove when its admissible sets form a closure system with a checkable minimal-repair algorithm.
