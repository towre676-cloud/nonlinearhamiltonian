## Revised question retained in the annual source

How should an increase in fitted R² be separated from evidence that ordered residual structure has disappeared?

## Status

Developed classical result with a checked example; recovered claims corrected where needed

## Summary

The source reports improved R² and fewer runs than expected. The two diagnostics examine different features. Projection geometry proves nondecreasing training fit for nested linear models, while a permutation null supplies the exact expected number of sign runs.

## Definitions

For a nonconstant response y, define R²=1−SSE/SST using the same sample and an intercept. Compare least-squares spaces V⊂W.

For residual signs with n₊ positive and n₋ negative values and no zeros, let R be the number of maximal consecutive constant-sign blocks. Under the null, all orderings of the signs are equally likely.

## Result name

Fit monotonicity and the expected run count

## Result statement

Nested least-squares spaces satisfy SSE_W≤SSE_V and R²_W≥R²_V. Under the random-order sign null, E R=1+2n₊n₋/(n₊+n₋). Neither claim makes the other diagnostic redundant.

## Proof

The minimization over W includes every candidate in V, proving the SSE inequality directly. For runs, write R=1+Σ_(i=1)^(n−1)I_i, where I_i indicates a sign change. A neighboring ordered pair has opposite signs with probability 2n₊n₋/[n(n−1)]. Summing gives the expectation. Thus adding regressors can lower squared residual magnitude while leaving a persistent sign pattern. If model selection used the same data, a large training R² increase is also not an out-of-sample theorem.

## Worked example: setup

## Worked example: calculation

The null expected count is 1+2·59²/118=60. A count 42 is eighteen below that mean; a p-value requires a specified exact or asymptotic null test. The reported increase 0.4311651513−0.3000468863 equals 0.1311182650, but its dataset and regression design were not recovered.

## Limits

Zeros, tied residuals, heteroscedasticity and dependence can change the sign-test model. No significance or model quality is inferred from the run ratio alone.
