## Revised question retained in the annual source

How much distinguishable information can a bounded scalar or prefix register store at a declared precision?

## Status

Developed mathematical treatment with explicit hypotheses, derivation and checked example

## Summary

Packing numbers quantify finite distinguishability without assuming binary hardware. A continuum of possible amplitudes becomes a finite number of robust messages once error is bounded, and a symbolic depth-k register has the same elementary information count.

## Definitions

Let a scalar register take values in [0,1], with readout error at most ε>0. Two encoded messages are reliably distinguishable only if their closed error intervals do not overlap.

A δ-separated set has pairwise distances at least δ. Its packing number counts the largest such set in a metric space.

A b-ary prefix register observed through k digits has b^k cylinders, each an observational equivalence class.

## Result name

Resolution bound for robust messages

## Result statement

If codewords require spacing greater than 2ε, at most 1+⌊1/(2ε)⌋ can fit in [0,1], with strict endpoint adjustments when equality occurs. A b-ary k-digit observation carries at most k log₂b bits of distinct-message information.

## Proof

Sort M scalar codewords x₁<…<x_M. Summing their adjacent gaps gives 1≥x_M−x₁>(M−1)2ε, yielding the bound with the stated strictness caveat. Conversely a uniform grid with spacing slightly above 2ε constructs nearly this many robust states. For prefixes, there are exactly b choices at each of k positions, so b^k possible observations; injectively labeling messages by them gives M≤b^k and log₂M≤k log₂b. Arithmetic values smaller than one can be encoded, but their fraction size alone does not increase this distinguishability bound.

## Worked example: setup

Suppose ε=.01 and use a grid with spacing .025.

## Worked example: calculation

The values 0,.025,…,1 give 41 robust messages because adjacent separation .025 exceeds .02. Their information is log₂41≈5.358 bits. A binary depth-six prefix register has 64 possible observations and six bits, while depth-five has 32. A continuous surface can use another alphabet, but its capacity comparison must retain its actual error and available range.

## Worked example: conclusion

Resolution, noise and coding make a proposed analog-computing claim mathematically testable.

## Limits

This bound concerns a bounded scalar with worst-case error. Parallel registers, temporal coding and correlated noise need their own channel model. No new computability class follows merely from using condensation, fractions or nonbinary levels.

## Extension

Specify a dynamical input-output channel and error distribution, calculate its metric entropy or Shannon capacity under an energy/time constraint, and construct a robust code with a matching achievable rate.
