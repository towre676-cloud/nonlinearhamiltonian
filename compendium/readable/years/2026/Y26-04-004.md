## Revised question retained in the annual source

What precise operator can be nonzero on a kernel, and when does the chain rule force it to vanish?

## Status

Developed classical result with a checked example; recovered claims corrected where needed

## Summary

The recovered notation D(Ψ∘Φ)|ker DΦ is ambiguous. If D denotes a Fréchet derivative, the expression is identically zero. If it denotes a coboundary I−P acting after raw transport, a genuine compatibility obstruction can remain. Both interpretations need explicit types.

## Definitions

For smooth maps Φ:X→Y and Ψ:Y→Z, write dΦ for the derivative. Separately take two-term complexes 0→Y⁰→^(δ_Y)Y¹→0 and 0→Z⁰→^(δ_Z)Z¹→0. Thus δ_Y:Y⁰→Y¹ and δ_Z:Z⁰→Z¹; each following differential is zero. No square-zero endomorphism is assumed.

Let A:X₀→Y⁰ and B₀:Y⁰→Z⁰ be raw linear transports. Define C=δ_ZB₀A:ker(δ_YA)→Z¹. A cochain map additionally includes B₁:Y¹→Z¹ with δ_ZB₀=B₁δ_Y. These coboundaries are not Fréchet derivatives.

## Result name

Chain-rule vanishing and a nonzero coboundary example

## Result statement

d(Ψ∘Φ) vanishes on ker dΦ. In contrast, the coboundary map C can be nonzero precisely because B₀ need not send ker δ_Y into ker δ_Z.

## Proof

The chain rule gives d(Ψ∘Φ)=dΨ∘dΦ, which annihilates every vector killed by dΦ. For the coboundary construction, η in the indicated kernel gives Aη∈ker δ_Y. Its image B₀Aη is δ_Z-closed exactly when Cη=0. Thus C measures the failure of B₀ to preserve this particular closed subspace. If a degree-one map B₁ satisfies δ_ZB₀=B₁δ_Y, then Cη=B₁δ_YAη=0, proving a sufficient, fully typed cochain-map condition. Without this intertwining, a nonzero C is ordinary linear algebra, not a contradiction of the chain rule or a second derivative.

## Worked example: setup

Take X₀=R and distinct copies Y⁰,Y¹,Z⁰,Z¹ of R². Let A(t)=(t,0), let δ_Y:Y⁰→Y¹ and δ_Z:Z⁰→Z¹ have matrix diag(0,1), and let B₀:Y⁰→Z⁰ and B₁:Y¹→Z¹ both have matrix [[0,1],[1,0]]. The next differentials Y¹→0 and Z¹→0 are zero.

## Worked example: calculation

δ_YA=0, so the full X₀ is the source kernel. B₀A(t)=(0,t), hence C(t)=(0,t)∈Z¹ is nonzero. The typed intertwining defect δ_ZB₀−B₁δ_Y:Y⁰→Z¹ has matrix [[0,−1],[1,0]]. Although each displayed differential matrix is not square-zero as a numerical endomorphism, the two-term complexes satisfy their actual composition-to-zero condition.
