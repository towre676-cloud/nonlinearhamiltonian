## Revised question retained in the annual source

Reconstruction: Which exact graph inequality turns a local hazard budget into a convergent path sum?

## Status

## Summary

The June source reports weighted self-avoiding-walk quantities below one while a scalar proxy failed. A finite matrix majorant gives a genuine sufficient criterion. It also makes clear that a finite observed nth-root value is not by itself a bound for every future length.

## Definitions

Let B be a finite nonnegative transition matrix on directed edge states, chosen so that every allowed nonbacktracking fault walk is represented. Let its maximum row sum be r<1.

For a nonnegative initial row u and terminal weights v with ||v||∞≤1, the length-n majorant is Z_n=uB^nv. A self-avoiding path family is a subset of these represented walks.

## Result name

A weighted path majorant proves an exponential tail under an explicit row-sum bound

## Result statement

Z_n≤||u||₁r^n, and Σ_{n≥d}Z_n≤||u||₁r^d/(1−r). The same upper bound holds for the summed weights of self-avoiding paths. A more flexible certificate is Bw≤rw for a strictly positive vector w, using the corresponding weighted norm.

## Proof

For nonnegative B, B1≤r1. Induction gives B^n1≤r^n1, so uB^nv≤uB^n1≤||u||₁r^n. Sum the geometric series for the tail. Dropping forbidden self-intersections only removes nonnegative path weights, proving the subset bound. For the weighted version, conjugate B by diag(w): its row sums are (Bw)_i/w_i≤r, so the same proof applies after transforming the initial and terminal weights. This is a finite Perron-style certificate and can capture heterogeneity lost in a uniform scalar degree bound. However a computed Z_12^{1/12}<1 alone does not imply an eventual r<1: a graph can have a low-weight transient region followed by a high-growth component that is reached later.

## Worked example: setup

Take B=[[1/5,1/10],[1/4,1/4]], u=(1,0), v=(1,1).

## Worked example: calculation

The maximum row sum is1/2, so Z_n≤2^{−n}. The tail from d=4 is at most1/8. Direct multiplication gives Z₀=1, Z₁=3/10, Z₂=11/100. These actual values are smaller than the majorant but do not change its universal proof. A weighted vector can reduce the bound when a common positive subeigenvector is available.

## Worked example: conclusion

The model supplies an explicit sufficient exponential envelope, not just a fitted path statistic.

## Limits

The source’s numericalΣ_w and Z₁₂ values are not recomputed without the native graph. A fault-probability theorem additionally needs a justified mapping from physical errors to weighted paths and a union bound over all relevant starts.

## Extension

Extract the native fault graph, exhibit a rational positive subeigenvector with r<1, and include the number of start sites to derive a complete finite-device failure bound.
