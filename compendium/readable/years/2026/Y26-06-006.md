## Definitions

## Result name

Sequential quantum instruments preserve probability only when every branch is included

## Result statement

The composed branches have Kraus operators L_{bs|a}K_{ar}. Summing all branches is trace preserving. Ignoring or renormalizing away failed branches changes the process and can conceal arbitrarily small success probability.

## Proof

Complete positivity of each branch follows directly from the Kraus form, including after adjoining any untouched auxiliary system. For completeness, sum(LK)†(LK) over b, s first; the conditional later identity collapses that sum to K†K. Summing a, r then gives I. Cyclicity of trace proves total output trace equals input trace. For a selected branch, normalization is nonlinear in ρ because of the dividing trace, so the selected normalized map is not itself the original linear channel. Any later resource analysis must weight branch costs and failures by their actual probabilities. This is an exact mathematical requirement, not a cosmetic reporting convention.

## Limits

This is a finite instrument theorem, not a certificate for a Fibonacci-anyon F-symbol table, a leakage-free six-anyon encoding or a hardware threshold. Those need their actual matrices and sectors.
