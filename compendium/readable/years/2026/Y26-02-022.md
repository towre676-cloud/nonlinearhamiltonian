## Summary

The based-path total space is contractible by one use of path induction. Its dependent-section consequence explains a valid transport kernel, while distinguishing this internal theorem from a translation preserving all judgments between foundations.

## Definitions

In intensional type theory let A be a type and a:A. Define P_a=Σ_{x:A}(a=x).

A type X is contractible when it has a center c:X and paths c=x for every x:X.

Identity elimination J proves a dependent property of paths by handling the reflexivity case. It is an axiom or rule of the chosen theory, not a result imported from a file name.

## Result name

Contractibility of the total based-path space

## Result statement

P_a is contractible with center (a,refl_a). For any family E over P_a, evaluation at the center identifies dependent sections with its fiber E(a,refl_a), up to the appropriate homotopies.

## Proof

Given (x,p):P_a, eliminate p. In the reflexivity case x=a and p=refl, so the required path from the center to (x,p) is reflexivity. J extends this proof to every p, establishing the contraction. Given an element e in the center fiber, transport e along the contraction paths to define a section at every point. Evaluation recovers e at the center, and path induction proves the inverse composite is pointwise equal to the original section; a statement of equality of functions uses function extensionality if the chosen formulation requires it. This makes explicit which rule supplies each step rather than hiding extensionality assumptions.

## Worked example: calculation

P_a has exactly the pair (a,refl), so its cardinality is one and a section is exactly one element of the corresponding fiber. For a two-element base A={0,1} and a=0, no pair with x=1 exists. This elementary model checks the theorem but does not exhibit higher paths or establish a universe-level equivalence of theories.
