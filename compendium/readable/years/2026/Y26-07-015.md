## Revised question retained in the annual source

What is tested when the residual subtracts quantities already tied by the assumed differential law?

## Status

Developed classical mathematics with explicit hypotheses and scoped evidence

## Summary

The July6 mass-ratio campaign reported very high identity-energy R² values. Those reports require the unrecovered dataset for empirical assessment. A direct differentiation theorem separates a valid invariant residual from a circular fit or an independent predictive test.

## Definitions

Let y_i,x_a be differentiable functions ofℓ, with fixed coefficients q_i,κ_i. Define z_i=d(y_i−q_ix_{a_i})/dℓ. Assume the model y_i′=κ_iγ_m+ε_i. A change of fixed units adds constants to the logarithmic variables.

## Result name

Exact residual decomposition and unit invariance

## Result statement

z_i=κ_iγ_m−q_ix′_{a_i}+ε_i. Fixed additive unit constants cancel from derivatives. If q_i varies, an extra−q_i′x_{a_i} term is mandatory.

## Proof

Differentiate the definition using the product rule, then substitute the model equation. This proves the decomposition without regression. Replacing a logarithm y_i by y_i+c_i and x_a by x_a+d_a leaves derivatives unchanged, proving the unit statement. If a comparison target is built from the same assumed derivative identity, its small residual tests internal algebra or numerical consistency, not independent explanatory power. A held-out target can be meaningful only if its data, coefficients and feature choices were fixed independently of the test. Very high R² alone does not reveal which of these situations occurred. A logarithm of a dimensional quantity should be read aslog(m/m₀) with a fixed reference unitm₀; differentiation removes the constantlogm₀. If the reference or coefficient changes withℓ, an extra derivative appears. Piecewise threshold models also require separate one-sided derivatives and matching conditions, so a smooth identity cannot be applied across an unexplained discontinuity.

## Worked example: setup

Take x(ℓ)=ℓ,y(ℓ)=3ℓ+7,q=2,κ=3,γ_m=1.

## Worked example: calculation

Both sides give z=1 exactly. Adding100 to y or subtracting4 from x changes nothing. If q(ℓ)=2+ℓ, however,z=d[3ℓ+7−(2+ℓ)ℓ]/dℓ=1−2ℓ; omitting q′ would incorrectly give1−ℓ.

## Worked example: conclusion

The invariant derivative is a genuine mathematical fact, while its empirical interpretation needs a separate test design.
