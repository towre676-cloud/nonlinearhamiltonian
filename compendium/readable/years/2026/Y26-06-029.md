## Definitions

A state is a functionσ:V→D on finitely many variables. An actionAreads onlyR_A⊆Vandchanges onlyW_A⊆V: its changed values depend solely onσ restricted toR_A.

Two actions satisfy the symmetric noninterference conditionsW_A∩(R_B∪W_B)=∅andW_B∩(R_A∪W_A)=∅. An admission condition may additionally require selected variables to retain specified values.

## Result name

Read-write footprint independence gives a sufficient commutation certificate

## Result statement

Under these conditions, A∘B=B∘Aon every state. A plan of pairwise noninterfering actions can be reordered arbitrarily without changing the final state. The conditions are sufficient rather than necessary.

## Proof

Because Bdoes not write any variable inR_A, action A sees the same read values before and after B; similarly B sees unchanged read values through A. Their write sets are disjoint, so neither overwrites the other’s outputs. On W_A each order therefore gives the same A value, on W_B the same B value, and outside the union the original value remains. This proves commutation coordinatewise. Any permutation is a product of adjacent swaps, so pairwise commutation proves arbitrary reordering by induction on swaps. Necessity fails, for example, when two actions both set the same variable to the same constant: their write sets overlap but their maps commute. Conversely disjoint write sets alone are insufficient because one may read a value the other changes.

## Limits

External effects, nondeterminism, aliasing and incomplete read sets can invalidate the model. A graph with omitted dependencies is not a proof of serializability or correctness.

## Extension
