## Summary

The separator-trace program asks for actual algebra rather than quotient counts. Min-plus matrices provide such algebra when their indices name the complete boundary state. Their multiplication proves optimal-path composition, but silently discarding a boundary label changes the optimization problem.

## Definitions

Use R∪{∞} with a⊕b=min(a,b), a⊗b=a+b and∞+a=∞. For compatible matrices define(A⊗B)_(i,k)=min_j(A_(i,j)+B_(j,k)).

An entry is the minimum cost of a transition between explicitly typed boundary states. Infinity represents an impossible transition.

## Result name

Typed min-plus matrix multiplication is exact dynamic programming

## Result statement

Min-plus multiplication is associative and composes the exact minimum costs of two stages. Independently minimizing two costs that share one hidden choice gives a lower bound, but can give a strictly unattainable total.

## Proof

Both parenthesizations of three matrices have entry min_(j,k)[A_(i,j)+B_(j,k)+C_(k,l)], proving associativity for finite index sets. Splitting a path at its common intermediate state gives exactly the two-stage formula: every path contributes one candidate, and minimizing over that state exhausts the allowed concatenations. For two functions f,g of one shared hidden state h, min_h(f(h)+g(h))≥min_hf(h)+min_hg(h). Equality requires at least one h that minimizes both when minima are attained. If each stage is allowed a different h after an index is erased, the smaller independent value need not be feasible.

## Worked example: setup

Take two hidden labels0,1 and costs f=(0,10),g=(10,0).

## Worked example: calculation

Each independent minimum is zero, but the two synchronized totals are both ten. Thus the true minimum is ten, not zero. A typed two-column interface retains the label and computes that value by min-plus contraction. A scalar interface that stores only the two separate minima has lost the correlation needed to recover it. This is a new exact example of the synchronization issue, not a reconstruction of the reported1,697-element basis.
