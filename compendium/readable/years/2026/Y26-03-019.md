## Revised question retained in the annual source

Which parts of the recovered anisotropy calculation are intrinsic and which depend on units?

## Status

Developed classical result with a checked example; recovered claims corrected where needed

## Summary

The source computes an anisotropy ratio from two singular values and notes that a rotation-dilation block has no anisotropy. Both statements are correct in a specified Euclidean metric. Arbitrary coordinate scaling changes ordinary singular values unless the metrics are transported.

## Definitions

For positive singular values s₁≥s₂ define B=(s₁−s₂)/(s₁+s₂), so 0≤B<1. Let J=[[-a,−b],[b,−a]].

If input and output metrics are positive matrices G and H, metric singular values are the square roots of eigenvalues of G⁻¹JᵀHJ.

## Result name

Rotation-dilation isotropy and coordinate covariance

## Result statement

For the displayed block J, JᵀJ=(a²+b²)I and B=0. Ordinary singular values are invariant under orthogonal coordinate changes; metric singular values are invariant under arbitrary coordinate changes when G and H are transformed consistently.

## Proof

Multiply the two-by-two matrices directly: cross terms cancel and both diagonal entries are a²+b². For a coordinate change x=Sx̃ and y=Tỹ, the matrix becomes J̃=T⁻¹JS, while G̃=SᵀGS and H̃=TᵀHT. Substitution shows G̃⁻¹J̃ᵀH̃J̃=S⁻¹(G⁻¹JᵀHJ)S, which has the same eigenvalues. If one instead resets both metrics to identity after a nonorthogonal scaling, one has changed the geometry rather than merely renamed coordinates. A dimensionless-looking ratio is not automatically coordinate-independent.
