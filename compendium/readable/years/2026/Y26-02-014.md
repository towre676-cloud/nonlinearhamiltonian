## Revised question retained in the annual source

What exact hypothesis makes a decision rule depend only on a public feature map?

## Status

Developed mathematical treatment with explicit hypotheses, derivation and checked example

## Summary

A function factors through an observation map precisely when it is constant on every observation fiber. This elementary theorem yields a sharp impossibility statement for indistinguishable valid and invalid histories, without asserting that every possible public verifier must use the same features.

## Definitions

Let X be a set of histories, F:X→Y an observed feature map and V:X→{0,1} a deterministic verifier.

Write x∼x′ when F(x)=F(x′), and restrict Y to F(X) when constructing a factorization.

A randomized verifier based only on F has an acceptance probability v(F(x)); equal features then imply equal acceptance laws.

## Result name

Fiberwise factorization criterion

## Result statement

There exists v:F(X)→{0,1} with V=v∘F if and only if V is constant on every fiber. If one fiber contains both a valid and an invalid history, no verifier based only on F can accept the former with probability at least 1−ε and the latter with probability at most ε for ε<1/2.

## Proof

Necessity follows by substitution: equal F values give equal v values. For sufficiency define v(y)=V(x) for any preimage x of y; fiberwise constancy proves independence of the choice. This is a set-theoretic factorization, requiring neither conical geometry nor secrecy. In the randomized case let the common acceptance probability be p. The two desired guarantees require p≥1−ε and p≤ε, impossible unless ε≥1/2. Consequently a lower bound requires construction of an actual mixed-validity fiber for the declared observation map, not merely a claim that the system has no secrets.

## Worked example: setup

Let X consist of binary words of length four and F record only the number of ones.

## Worked example: calculation

The words 0011 and 0101 both have F=2. If the specification declares adjacent ones valid and separated ones invalid, the fiber contains opposite labels. A count-only verifier cannot distinguish them, whereas a verifier reading the full word can. Likewise the homometric Fourier patterns in the spectral example are indistinguishable to power-only features but distinguishable to their original sequences.

## Worked example: conclusion

The limitation belongs to a precise observation algebra, rather than to all computation in a public system.

## Limits

Absence of a secret does not force every verifier to factor through a proposed spectral or holonomy score. Different public data, external anchors and richer observations may refine fibers; their properties need separate proofs.

## Extension

For a supplied verification task, characterize the coarsest sufficient observation partition. Construct explicit valid/invalid collisions or prove separation, and quantify robustness when feature values are known only within a stated error tolerance.
