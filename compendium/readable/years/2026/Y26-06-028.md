## Result name

Lossless reconstruction forces injectivity and gives a counting lower bound on compression

## Result statement

A lossless encoder is injective. A fixed-length lossless code forNinputs needsb≥ceil(log₂N). No injective binary encoder can strictly shorten every binary string of lengths at mostb. The exact source byte gaps can be audited arithmetically but do not prove universality of a compression model.

## Proof

If E(x)=E(y), applying the same decoder gives x=y, proving injectivity. Counting the available b-bit words proves the fixed-length bound. For the shortening claim, the input set has 2^{b+1}−1 strings, while all possible outputs of length at most b−1 number 2^b−1, fewer than the inputs. Pigeonhole then forces a collision. Allowing a different decoder D_x for every original x defeats the argument only by hiding x inside the decoder; charging that side information restores a genuine code. Prefix-free variable-length coding adds Kraft’s inequality and permits a distribution-dependent expected-length theorem, but it still cannot shorten every possible input. Thus format-aware gains are real finite dataset properties, not contradictions of incompressibility.
