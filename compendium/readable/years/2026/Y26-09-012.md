Which directions are lost by each exceptional fault, and which added vector repairs both cases?

## Summary

The pair-fault report described two151-dimensional exceptional spans inside a152-dimensional algebra and a150-dimensional universal core. A small exact model proves the repair logic without pretending to reconstruct the missing algebra matrices.

## Definitions

Let V be d-dimensional and H₁,H₂ distinct hyperplanes. Write H_i=kerℓ_i for nonzero linear functionals.

A repair vector v enlarges H_i to V exactly when its image in V/H_i is nonzero, or equivalently ℓ_i(v)≠0.

## Result name

Two exceptional hyperplanes have a common core and an exact repair criterion

## Result statement

The common core H₁∩H₂ has dimension d−2. A single vector repairs both exceptional spans exactly when both linear tests ℓ₁(v),ℓ₂(v) are nonzero. For independent repair directions, the excluded coefficients are two coordinate hyperplanes.

## Proof

Distinct hyperplanes have nonproportional defining functionals, so the map x↦(ℓ₁(x),ℓ₂(x)) has rank two. Rank-nullity gives the intersection dimension. Since V/H_i is one-dimensional, adjoining v gives all of V if and only if v has nonzero quotient class, proving the criterion. Choose a basis adapted to the intersection, with one additional direction in each hyperplane. In those coordinates the two tests read the complementary coefficients, making the exceptional parameter sets explicit.

## Worked example: setup

Take V=Q⁴, H₁=span(e₁,e₂,e₃), H₂=span(e₁,e₂,e₄), and v=αe₃+βe₄.

## Worked example: calculation

The universal core is span(e₁,e₂), dimension two. H₁ is repaired precisely when β≠0; H₂ precisely when α≠0. Choosing α=β=1 repairs either individual fault without changing the repair vector. Choosing α=0,β=1 repairs the first but leaves the second defective. Exact matrix ranks distinguish all four zero/nonzero coefficient cases.

## Worked example: conclusion

The claimed repair pattern has a complete quotient-space explanation and an exact algebraic test.
