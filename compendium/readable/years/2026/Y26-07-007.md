## Revised question retained in the annual source

Which quotient counts distinct character shifts, and when does the source’s dimension formula apply?

## Status

## Summary

The source reports2^a sectors from a quotient involving G and Q. Quotient cardinality is elementary, but identifying it with character transitions requires the correct kernel. The exact transition theorem both proves the constructive part and identifies an assumption that cannot be omitted.

## Definitions

Let Q be an r-dimensional isotropic binary Pauli subspace with independent commuting Hermitian generators. Its joint eigenspaces are H_χ,χ∈F₂^r. For v define δ_v(q)=ω(v,q). Let G be any binary subspace of possible Pauli interventions.

## Result name

Character transport and orbit cardinality

## Result statement

P(v)H_χ=H_(χ+δ_v). The number of reachable character shifts is2^rankδ=2^[dimG−dim(G∩Q^⊥)]. Replacing Q^⊥ by Q requires the extra identity G∩Q^⊥=G∩Q.

## Proof

If ψ has eigenvalue(−1)^χ(q) under P(q), commuting P(q) past P(v) multiplies it by(−1)^ω(q,v), giving the shifted character. P(v) is invertible, so this is an equality of eigenspaces. The shift map G→Q* is linear with kernel G∩Q^⊥; rank-nullity proves its image cardinality. Independently, every joint character sector has dimension2^(n−r): its projector is the product of r factors(I+(−1)^χ_jP(q_j))/2, and all nonidentity Pauli terms have trace zero. A formula using dimG−dim(G∩Q) counts a different vector-space quotient unless the kernels agree. The character-shift map is linear overF₂, so all nonempty fibres have the same size2^{dim(G∩Q⊥)}. Its image acts freely by translations on the character labels, and the orbit size is exactly the image cardinality. This proves the sector-count statement through an explicit action, without conflating the stabilizer with an unrelated isotropic subgroup.
