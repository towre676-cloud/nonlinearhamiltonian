## Revised question retained in the annual source

How can a mathematically exact identity be numerically unstable, and which error bound detects that instability?

## Status

Classical mathematics or a newly chosen finite model developed with proof; historical claims delimited

## Summary

The retrieved condition number concerns the sum of terms, rather than the intrinsic truth of the identity. A direct perturbation bound makes its scope precise. It also explains why common-mode symbolic cancellation should occur before evaluating large nearly opposite quantities.

## Definitions

Let S=Σ_(j=1)^n t_j≠0 be a real or complex sum. Define κ_sum=Σ|t_j|/|S|.

Assume perturbed terms satisfy |Δt_j|≤ε|t_j|; this is an input relative-error model, separate from the additional error of the summation algorithm.

## Result name

Sharp first-order relative perturbation bound

## Result statement

|ΔS|/|S|≤εκ_sum. For real terms the bound can be attained by suitable independent signed perturbations. If S=0, relative conditioning is undefined and an absolute error bound must be used instead.

## Proof

The triangle inequality gives |ΣΔt_j|≤Σε|t_j|, proving the bound. For real terms, choose every Δt_j with the same sign, of magnitude ε|t_j|; then their sum has magnitude εΣ|t_j|, giving equality. Since |Σt_j|≤Σ|t_j|, κ_sum≥1. For complex terms the same upper bound holds and alignment of perturbation directions similarly attains it under the stated independent complex-error balls. This is a worst-case conditioning theorem; a particular floating-point algorithm can add further rounding errors, while correlated input errors may cancel and require a joint model. Therefore a large κ is a warning about sensitivity, not a proof that any computed value is wrong.

## Worked example: calculation

For t₁=10¹²+1 and t₂=−10¹², S=1 and κ_sum=2·10¹²+1. Independent relative errors of only 10⁻¹² can therefore create absolute errors around two, larger than the true result. If both terms come from the exact common expression c, computing (c+1)−c symbolically as one removes the common uncertainty before numeric evaluation. This is valid only when the two c occurrences really represent the same quantity.

## Worked example: conclusion

The condition number quantifies precisely how cancellation can magnify independent term errors.

## Limits

It is not an a posteriori interval certificate and does not bound errors in unrecovered historical high-precision calculations. Correlations, exact rational arithmetic and compensated summation alter the appropriate error model.

## Extension

For a supplied special-function identity, derive interval enclosures for its individual terms, simplify shared algebraic pieces, and bound the final absolute residual with directed error control before interpreting extra decimal digits.
