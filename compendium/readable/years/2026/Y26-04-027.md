## Summary

The source correctly warns that a published basis for another matrix cannot substitute for the actual input-dependent B_x. Its path-difference identity is immediate; on a finite directed acyclic graph a stronger spanning statement follows from flow decomposition.

## Definitions

Let a finite directed acyclic graph have source s and sink t, with every edge lying on an s-to-t path. Orient its incidence matrix B with −1 at tails. Let χ(p) be the edge-indicator vector of a directed path.

Every such path satisfies Bχ(p)=e_t−e_s. Fix one reference path p₀.

## Result name

Path-difference spanning theorem

## Result statement

B(χ(p)−χ(p₀))=0 for every path. Moreover the real kernel of B is spanned by these path differences under the stated DAG and edge-coverage hypotheses.

## Proof

The kernel identity is subtraction. For the converse, take z∈ker B and construct a strictly positive feasible s-to-t flow f by summing one covering path for each edge. For sufficiently small ε>0, both f and f+εz remain nonnegative and have the same divergence. Every nonnegative flow on a finite DAG decomposes into nonnegative path flows: start at a positive source edge, follow conservation until reaching the sink, subtract the smallest path-edge flow, and repeat; acyclicity prevents an endless loop. Therefore f and f+εz are linear combinations of path indicators with the same total coefficient, equal to their source flow. Subtracting cancels that total and expresses εz as a linear combination of differences from p₀.

## Worked example: setup

Use a diamond s→a→t and s→b→t.

## Worked example: calculation

In edge order (sa,at,sb,bt), the two paths have vectors (1,1,0,0) and (0,0,1,1). Their difference (1,1,−1,−1) spans the one-dimensional incidence kernel.

## Worked example: conclusion

The exact matrix and graph determine both the kernel and its path interpretation.

## Limits

The spanning proof uses a finite DAG and edge coverage. Directed cycles can add circulation components requiring separate cycle generators.

## Extension

For each actual input x, publish B_x, enumerate its admissible path polytope and certify a basis with exact arithmetic before comparing any external reference basis.
