## Revised question retained in the annual source

How should a second-order recurrence be fitted and then falsified by the recovered six-jet?

## Status

## Summary

The source corrects a proposed two-term linear recurrence. The reliable methodology is to separate fitting equations from new predictions. This turns a suggestive pattern into a finite, reproducible exclusion for a precisely stated model class.

## Definitions

Let a₁,…,a₆ be the displayed coefficients. Consider a_n=c₁a_(n−1)+c₂a_(n−2) for every n≥3, with constants c₁,c₂.

Fit c₁,c₂ from the n=3 and n=4 equations only. The coefficient matrix is [[a₂,a₁],[a₃,a₂]], whose determinant is a₂²−a₁a₃.

## Result name

Fitted recurrence prediction test

## Result statement

If the determinant is nonzero, the model has at most one fitted pair. A mismatch at n=5 excludes every constant-coefficient second-order recurrence satisfying all six inputs.

## Proof

The first two recurrence equations form a nonsingular linear system, so any candidate matching the six coefficients must equal its unique solution. Predict a₅ using the actual a₄ and a₃; predict a₆ using the actual a₅ and a₄ if testing the equation directly. A nonzero residual in either equation is decisive for the exact input data. Propagating the predicted a₅ instead defines a different multi-step forecast and should not be confused with the direct n=6 residual. With rounded data, interval bounds on the fitted pair and predictions are needed to conclude exclusion for all possible underlying exact coefficients.

## Worked example: setup

Use the six displayed decimal coefficients as rational input values.

## Worked example: calculation

The fit gives c₁≈−1.3091562007 and c₂≈0.1289216815. It predicts a₅≈8.4268522254, whereas the source input is 9.1305430243, a residual about 0.7036907989. The direct sixth prediction, using the actual fifth input, is −12.7284639575, a residual −1.6414629772. Propagating the predicted fifth value instead gives the source’s −11.8072227848 and residual −2.5627041499; these are different tests.

## Worked example: conclusion

The failure occurs on coefficients withheld from the fit and excludes this recurrence model for the declared decimals.

## Limits

This does not exclude variable-coefficient recurrences, higher order recurrences or differential algebraic relations. No exact germ theorem follows from rounded six-digit tests alone.

## Extension

Enclose each coefficient at its known precision, bound the two prediction residuals away from zero by rational interval arithmetic, and compare the smallest recurrence order supported by additional exact jets.
