## Revised question retained in the annual source

Which exact optimum improves when semantics-preserving choices are added, and how are search and model errors separated?

## Status

Proved for the stated exact model; historical large-run claims remain unverified

## Summary

The August source distinguishes semantic equivalence from deployment feasibility and from a hardware model’s accuracy. This is a useful mathematical separation: an equivalence class may be large while only a small subset is admissible, and a proved modeled optimum need not be an observed physical optimum.

## Definitions

Let π:Θ→F map parameters to their exact represented function. The semantic fiber is E(f)=π⁻¹({f}). Let D⊂Θ encode all declared deployment constraints, and let Y_H(θ) be the feasible implementation choices on a fixed target H.

Define K(S)=inf{C_H(θ,y):θ∈S,y∈Y_H(θ)}, with inf∅=+∞. A minimum requires attainment, which is automatic for a nonempty finite feasible set but not for an arbitrary continuous fiber.

## Result name

Feasible-set monotonicity and a certified error decomposition

## Result statement

If S⊂T⊂E(f)∩D, then K(T)≤K(S). A returned feasible cost ĉ satisfies ε_search=ĉ−K(T)≥0. If a physical cost z obeys |z−ĉ|≤δ_model+δ_measure, then |z−K(T)|≤ε_search+δ_model+δ_measure.

## Proof

Every feasible pair allowed by S is allowed by T, so taking an infimum over T cannot increase the value. This proof needs inclusion of full parameter–implementation pairs, not merely a parameter transformation that breaks quantization or architecture constraints. For a feasible returned pair, its cost is one member of the set minimized over, hence ĉ≥K(T). Add and subtract ĉ in z−K(T) and use the triangle inequality, obtaining the error bound. Search error can therefore be driven to zero by exhaustive finite enumeration or a matching lower bound, while model discrepancy remains logically independent. If the source uses a nonlinear calibration g from modeled cost to observation, one additionally needs an explicit bound for g rather than identifying its units with C_H.

## Worked example: setup

Use an exact two-parameter semantic model π(a,b)=a+b with target function value one. Declare deployment states S={(1,0)}, T={(1,0),(0,1),(1/2,1/2)} and costs 12,9,10.

## Worked example: calculation

K(S)=12 and K(T)=9. Returning the third state costs10, so search regret is1. An observation z=10.4 with total calibrated discrepancy bound0.5 obeys |z−K(T)|=1.4≤1.5. Excluding the cost-nine state by an actual deployment constraint changes the true feasible optimum to10.

## Worked example: conclusion

The example demonstrates both exact improvement and the need to keep feasibility and error layers explicit.
