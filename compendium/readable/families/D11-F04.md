## Central question

How much can an observation distinguish, and what information does a summary discard?

## Synopsis

Several source questions use entropy, spectral flatness, phase concentration, compression or correlation as a proxy for a richer structure. Their strongest mathematical development begins by specifying the observation map and its fibres. A summary can be exactly computed and still fail to separate the objects relevant to the question. Conversely, an injective finite encoding supports exact recovery regardless of whether its values resemble a preferred statistical distribution. This family organizes capacity and diagnostics as distinct operations: counting distinguishable messages, preserving information under a reversible map, and measuring one chosen feature of a data object.

## Definitions

An observation h:X→Y induces equivalence x∼x′ when h(x)=h(x′). Exact reconstruction from h exists precisely when the required target is constant on each fibre.

A lossless finite encoder E has a decoder D with D(E(x))=x, hence must be injective.

A b-ary prefix X_1,…,X_k has entropy H_k; its increment is conditional entropy, lying between zero and log b.

For positive powers P_i, spectral flatness is (∏P_i)^{1/n}/((ΣP_i)/n). For phases θ_j, circular resultant is |Σe^{iθ_j}|/n.

## Theorem

A lossless fixed-length binary code for N objects needs b≥ceil(log_2N). No injective binary encoder can strictly shorten every binary string of lengths at most b. Prefix entropy obeys H_{k+1}−H_k=H(X_{k+1}|X_1,…,X_k), independently of a metric contraction placed on the symbolic space.

## Proof

Injectivity follows by applying D to a collision E(x)=E(x′). A b-bit codomain contains only 2^b addresses, so N≤2^b. For universal shortening, the number of strings of lengths at most b is 2^{b+1}−1, whereas all shorter outputs through length b−1 number only 2^b−1; the pigeonhole principle rules out injectivity. The entropy chain rule follows by factoring p(x_1,…,x_{k+1}) into p(x_1,…,x_k)p(x_{k+1}|x_1,…,x_k) and expanding the logarithm in the expectation. Conditional entropy is nonnegative and at most log b. No property of an externally imposed ultrametric enters this algebra, so a metric contraction alone cannot prove an entropy decrease.

## Worked example: setup

Suppose five feasible objects are indexed by three bits, and examine two phase populations: all phases zero, or half zero and half π. Compare flat and nonflat power arrays.

## Worked example: calculation

Three bits suffice because ceil(log_25)=3. Drawing a uniform three-bit address and rejecting 5,6,7 yields each valid object with probability 1/5. Taking the address modulo five instead gives probabilities (2,2,2,1,1)/8. The all-zero phase population has resultant one; the two-opposite-cluster population has resultant zero despite being sharply concentrated in two directions. Powers (1,1,1,1) have flatness one, while (1,1,1,9) have flatness √3/3<1. Neither flatness nor resultant defines a false-acceptance exponent without an observation and null model.

## Worked example: meaning

The useful output is a hierarchy of observables, each with a declared invariance and a known failure mode. AUROC preserves ranking but discards calibration. Spectral power discards phase. A finite entropy calculation records empirical symbol balance but cannot establish decimal normality. A reversible code preserves object identity but does not imply shorter descriptions for every object. These distinctions turn diagnostics into well-typed tools.

## Limits

A real number contains arbitrarily many formal digits but a finite-resolution device distinguishes only finitely many separated values. Strict spacing conventions matter at endpoints. Differential entropy changes under coordinates, while message count does not. The examples supply no empirical hardware capacity, compression benchmark or false-acceptance rate. Those require raw data and operational noise models.

## Open questions

For a supplied finite observation map, enumerate fibres and compute which target functions factor through it.

Design a sufficient diagnostic panel for a specified finite family, minimizing measurement cost while preserving target distinctions.
