# Quartic dynamic-core tables — computed refinements against the repository's definition

This package computes dynamic-core data for a representative, explicitly listed set of quartic Hamiltonians from Cody's `nonlinearhamiltonian` project, in exact rational arithmetic, cross-checked against two independent implementations. It is committed on the branch `muse/quartic-dynamic-cores` for review by pull request. Its cross-checks use `engine.py`, already in this directory on main, and `moyal_partner_checker.py`, which is added in the same directory by pull request #3 (branch `muse/moyal-independent-checker`); after both are merged, `quartic_cores.py` finds both engines beside itself in this directory.

## The definition used — the repository's own, quoted

No definition was invented for this work. The repository defines the object in three mutually consistent places, and the computation implements exactly that definition.

`programmes/DYNAMIC_CORE_RESULTS.md`, opening section, states the setting as one canonical pair with coefficients in **Q** under the flat Weyl–Moyal convention, with $D = \{H,\cdot\} = H_q \partial_p - H_p \partial_q$ and $C_k = T_k(H,\cdot)$ for the nonzero odd transvectants with $k \ge 3$, and then defines verbatim:

$$D_\infty(H) = \{\, G \in \mathbb{Q}[q,p] : C_k D^r G = 0 \text{ for all odd } k \ge 3 \text{ and all } r \ge 0 \,\}.$$

`programmes/HAMILTONIAN_CORES.md` gives the same object as $\mathcal{D}_\infty(H) = \{G \in R : C_j D^r G = 0 \text{ for every } j \ge 1, r \ge 0\}$ with $C_j = T_{2j+1}(H,\cdot)$, and `research/hamiltonian/dynamics/proofs.md` gives the equivalent refinement form $K_j(H) = \bigcap_{r=0}^{j} \ker(L_{H_4}\delta_H^r)$, $D(H) = \bigcap_{j \ge 0} K_j(H)$, noting that $D(H)$ is exactly the largest $\delta_H$-invariant subspace contained in the one-step partner space $E(H)$. Every Hamiltonian treated here has total degree 4, so $T_k(H,\cdot) = 0$ for $k \ge 5$ (a $k$-th transvectant differentiates $H$ exactly $k$ times) and the **only nonzero gate is $C_3 = T_3(H,\cdot)$**, with $T_k$ taken in the explicit form printed in `research/hamiltonian/quartic/proofs.md`. The two cross-check engines impose all odd Moyal gates simultaneously, so their agreement with the $T_3$-only computation also confirms that omitting $k \ge 5$ loses nothing for these Hamiltonians.

## What was computed, and the exact logical status of each piece

The script `quartic_cores.py` (standard library only, `fractions.Fraction` throughout, all paths relative to the script file) computes, for each homogeneous Hamiltonian and each degree $n \le 16$, the refinement spaces $S^R_n(H) = \{G \in V_n : T_3(H, D^r G) = 0 \text{ for } r = 0, \dots, R\}$ for $R = 0, \dots, 8$, where $S^0_n$ is the one-step partner space $E_n$ and every $D^r$ image is kept as a full polynomial with no projection. Because the true core requires the conditions for **all** $r$, one has $D_\infty(H)_n \subseteq S^R_n(H)$ for every $R$, so each computed dimension is a **rigorous upper bound** on the core dimension in that degree, not a heuristic sample. In every degree computed, the dimension of $S^8_n$ equals the dimension of the repository's proved core in that degree, and the computed basis is the proved family's basis; combined with the inclusion just stated and with the repository's all-degree theorems cited per case below, the per-degree core is thereby determined exactly in every degree $n \le 16$ tabulated. The computation also verifies directly that $D$ maps each computed truncated core space $S^8_n$ into $S^8_{n+2}$ throughout the computed range, which is the finite shadow of the invariance in the definition. For the inhomogeneous Hamiltonian $qp^3 + q^2$ the script computes $K_R^{\le 8} = \{G : \deg G \le 8,\ T_3(H, D^r G) = 0 \text{ for } r \le R\}$ over all 45 monomials of degree at most 8, again with unprojected images; since $D_\infty(H) \cap \{\deg \le 8\} \subseteq K_R^{\le 8}$ for every $R$ and the computed $K_4^{\le 8}$ already equals $\operatorname{span}\{1, H\}$, this proves **unconditionally, from the computation alone**, that no polynomial of degree at most 8 outside $\operatorname{span}\{1, H\}$ lies in the dynamic core of $qp^3 + q^2$. The all-degree statement for that Hamiltonian is the repository's theorem, not this computation.

## Headline results

The truncated core dimensions in degrees $n = 0, 1, \dots, 16$ came out as follows, and in each homogeneous case a **single** extra bracket ($R = 1$) already reduced the partner space to the final core in every degree where any reduction occurred, with no further change through $R = 8$. For $H = q^4$ (root type $(4)$) the dimensions are $1, 2, 3, 3, 3, \dots$, the graded pieces of the proved core $\mathbb{Q}[q] \oplus p\,\mathbb{Q}[q] \oplus p^2\,\mathbb{Q}[q]$, with degree-$n$ basis $q^n$, $q^{n-1}p$, $q^{n-2}p^2$; here no refinement step removes anything, because the strip is already $D$-invariant. For $H = q^3p$ (type $(3,1)$) the dimensions are $1, 2, 2, 2, \dots$, the pieces of $\mathbb{Q}[q] \oplus p\,\mathbb{Q}[q]$ with basis $q^n$, $q^{n-1}p$; the partner space is one dimension larger exactly in degrees $n \equiv 2 \pmod 4$, where the exceptional static monomials $q^c p^{3c+2}$ (namely $p^2$ in degree 2, $qp^5$ in degree 6, $q^2p^8$ in degree 10, $q^3p^{11}$ in degree 14) survive $R = 0$ and are all killed at $R = 1$, exactly as the repository's remark that these exceptional monomials drop out of the core predicts. For $H = qp^3$, the $q \leftrightarrow p$ mirror, the dimensions are again $1, 2, 2, 2, \dots$ for the proved core $\mathbb{Q}[p] \oplus q\,\mathbb{Q}[p]$ with basis $p^n$, $qp^{n-1}$, and the exceptional monomials $q^{3c+2}p^c$ drop at $R = 1$ in the same degrees. For $H = q^2p^2$ (type $(2,2)$) the dimensions alternate $1, 0, 1, 0, \dots$, the pieces of $\mathbb{Q}[qp]$ with basis $(qp)^{n/2}$ in even degrees; the partner space, which also contains every pure power $q^n$ and $p^n$, collapses to the diagonal at $R = 1$ in every degree. For the two distinct-root Hamiltonians $H = q^4 + p^4$ ($\lambda = 0$) and $H = q^4 + q^2p^2 + p^4$ ($\lambda = 1$) the dimensions are $1$ in degree 0, $1$ in degree 4 with basis $H$ itself, and $0$ in every other degree through 16, matching the proved core $\operatorname{span}\{1, H\}$; in particular the degree-6 partner space is 3-dimensional and the degree-4 partner space is 2-dimensional (spanned by $H$ and its Hessian), yet one bracket kills everything except the line through $H$. For the inhomogeneous contrast $H = qp^3 + q^2$, whose one-step partner space is **identical** to that of $qp^3$ because the $q^2$ term contributes nothing to $T_3$, the refinement dimensions over the degree-$\le 8$ candidate space fall as $19, 12, 6, 4, 2$ for $R = 0, 1, 2, 3, 4$ and then remain $2$ through $R = 10$, with final basis exactly $\{1,\ qp^3 + q^2\}$. This is the sharpest contrast in the table: adding $q^2$ leaves every static partner untouched while collapsing an infinite-dimensional core, $\mathbb{Q}[p] \oplus q\,\mathbb{Q}[p]$ for $qp^3$ alone, to the two-dimensional $\operatorname{span}\{1, H\}$, and the computation shows the collapse needs depth $R = 4$ in this bounded space rather than the single step sufficient for the homogeneous representatives. Full per-degree dimensions, refinement sequences, and bases for all degrees up to 16 are in `quartic_cores.json`.

## Cross-checks performed

The partner spaces were checked three independent ways. This script's $T_3$ nullspaces agree in dimension **and** in span with `moyal_partner_checker.py` (the independent bidifferential-operator checker) and with the repository's `research/hamiltonian/independent/engine.py` (the defining star-product engine behind `partner_lab.py`) for every Hamiltonian and every degree $n \le 12$, and the correction-free verdicts on all monomials $q^a p^b$ with $a + b \le 6$ agree across all three implementations for every Hamiltonian. The static dimensions also reproduce the repository's proved Hilbert function $\dim E_n = 2 + \mathbf{1}_{e \mid (n-2)}$ from `quartic/proofs.md` in every degree, with $e = 1$ for $q^4$, $e = 2$ for $q^2p^2$, and $e = 4$ for the other four homogeneous cases. A rerun of the script reproduced `quartic_cores.json` byte-for-byte (identical SHA-256), and the run log `quartic_cores.log` is the output of an actual execution.

## What is proved, what is computed, and what is not claimed

The **all-degree** core descriptions quoted above — the strip for $q^4$, the affine strips for $q^3p$ and $qp^3$, $\mathbb{Q}[qp]$ for $q^2p^2$, $\operatorname{span}\{1, H\}$ for the two distinct-root quartics and for $qp^3 + q^2$ — are the repository's theorems (`DYNAMIC_CORE_RESULTS.md` §3c table and distinct-roots theorem, §2 table and §3 quadratic-perturbation theorem, and `dynamics/proofs.md`), and this package does not re-prove them. What this package adds is **computed** evidence of a specific, rigorous kind: exact per-degree upper bounds $S^8_n$ that meet those proved cores in every degree $n \le 16$, explicit bases, the observed stabilisation depths ($R = 1$ for all six homogeneous representatives, $R = 4$ for the bounded inhomogeneous problem), a three-way independent cross-check of the underlying partner spaces, and an unconditional degree-$\le 8$ exclusion for $qp^3 + q^2$. It is **not** claimed that stabilisation at $R = 1$ or $R = 8$ in the computed range proves anything about degrees above 16 or depths beyond those computed for a general quartic; the repository itself warns that a plateau of bounded-degree dimensions is not a stopping proof, and for a general distinct-root quartic $\lambda$ the required depth varies (its per-degree certificate records depth $R = 3$ in degree 1 for the equianharmonic class $\lambda^2 = -12$, which is not among the representatives computed here). No claim is made about quartics outside the seven listed Hamiltonians beyond what the repository's root-type theorems already give, nothing is claimed about cubic or higher-degree perturbations, analytic operator domains, or global flows, and no literature-priority claim is made for any of these computations.

## Files

`quartic_cores.py` is the portable exact script (run it with `python3 quartic_cores.py`; it writes `quartic_cores.json` beside itself and locates both cross-check engines relative to its own path). `quartic_cores.json` is the full machine-readable table with the definition, parameters, per-case root types, partner dimensions, refinement sequences, truncated core dimensions, bases, and cross-check flags. `quartic_cores.log` is the captured output of the verified run. This file, committed as `QUARTIC_DYNAMIC_CORES.md`, is the human-readable summary.
