# Pure-coordinate boundary: exact all-degree classification

Let \(K\) be a characteristic-zero field and \(H=h(q)\in K[q]\), \(\deg h=6\). Define the odd transvectants by

\[
T_k(F,G)=\sum_{i=0}^k(-1)^i\binom{k}{i}(\partial_q^{k-i}\partial_p^i F)(\partial_q^i\partial_p^{k-i}G),
\]

and \(D_H=T_1(H,-)\). Then

\[
T_3(H,G)=h'''(q)\partial_p^3G,\qquad
T_5(H,G)=h'''''(q)\partial_p^5G.
\]

Since \(h'''\ne0\) and \(K[q,p]\) is an integral domain, \(T_3(H,G)=0\) if and only if \(\partial_p^3G=0\). In characteristic zero this is equivalent to \(\deg_p G\le2\). Such \(G\) automatically satisfies \(T_5=0\). Hence

\[
S^0(H)=K[q]\oplus pK[q]\oplus p^2K[q].
\]

Also \(D_H=h'(q)\partial_p\), which preserves this space. Thus

\[
S^r(H)=S^0(H)\quad(r\ge0),\qquad
D_\infty(H)=S^0(H),
\]

an infinite-dimensional \(K\)-vector space.

This result covers the pure-coordinate boundary only. It does not imply any classification for mixed \(q,p\) terms, and it does not establish full 21-parameter closure. A coordinate-swapped analogue holds for \(H=h(p)\).
