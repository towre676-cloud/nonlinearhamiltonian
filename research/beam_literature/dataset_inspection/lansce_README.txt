* The "dataset_details.pdf" file contains a brief description of the dataset.
* The dataset is used for the python code available at "https://github.com/mahindrautela/CLARM"
* About the dataset:
- "run9ps.npy" is a numpy file containing 6D phase space as 500 examples of 4D object. The shape of the array is 500 x 48 x 15 x 256 x 256.
- "run9rf.npy" is a numpy file containing RF settings as 500 examples of 1D object. The shape of the array is 500 x 8.
* Due to the limit on the dataset size in Zenodo, only 500 examples are uploaded out of 1500 examples. Email: mrautela@lanl.gov for more data.
* The dataset is approved from LANL for open-source uploads. The LA-UR number of the submission is LA-UR-24-22495.
