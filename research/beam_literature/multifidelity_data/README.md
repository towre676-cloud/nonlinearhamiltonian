# Public FBPIC optimization archive: verified ingestion

Attribution: Faran Irshad, Stefan Karsch and Andreas Döpp, *Reference dataset of multi-objective and multi-fidelity optimization in laser-plasma acceleration*, version 0.1.0 (2023), DOI [10.5281/zenodo.7565882](https://doi.org/10.5281/zenodo.7565882). Associated article: *Physical Review Research* 5, 013063 (2023), DOI [10.1103/PhysRevResearch.5.013063](https://doi.org/10.1103/PhysRevResearch.5.013063). The live record API declares **CC-BY-4.0**. The exact source ZIP is retained without modifications.

Run `python research/beam_literature/inspect_multifidelity_data.py --output research/beam_literature/multifidelity_data/inspection.json` from the repository root. Add `--download` to reacquire the pinned source bytes. The script verifies the publisher MD5, our SHA256, ZIP CRCs and numeric arrays, using `allow_pickle=False`. It does not execute third-party code or rerun FBPIC.

The combined archive contains **2,443 rows**, with **2,286 unique encoded five-column inputs**. Inputs lie in the unit cube; they are not the raw physical coordinates named by the dataset description. There are **six exact-input groups with differing objective labels**, involving sixteen rows. The archive does not identify whether this comes from stochastic replication, hidden settings, normalization conventions or another cause. Treating the table as a noiseless single-valued simulator is therefore unjustified.

Only **fifteen** exact first-four-column groups have more than one stored fidelity value; **twelve** have fidelity spread at least 0.05. The archive is not a dense matched low/high-fidelity validation grid. Its **407 zero-charge rows** all have encoded penalties of -300 for the target-energy-distance objective and -1000 for bandwidth. These rows should not silently disappear from training or reported quality.

All twelve substantially paired groups sit at encoded unit-cube corners. Comparing their lowest and highest stored fidelities, mean charge increases in five groups, decreases in two and remains zero in five. These are descriptive observations over a small selected set, not a calibrated global fidelity trend. The paired archive does not validate interior control settings across fidelity.

The ZIP contains fourteen `.npy` files arranged into combined, multiobjective and five single-objective subfolders. It supplies no per-row runtime, initial-particle data, random seed or optimization-run identifier. Thus the data are useful for investigating model discrepancy and reproducing published objective conventions, but cannot alone validate a new optimizer's wall-clock gain or a uniform physical error bound. The numerical summary and every conflicting group are preserved in `inspection.json`.
