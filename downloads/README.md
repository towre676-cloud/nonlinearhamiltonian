# Portable source downloads

These six archives contain the authored reports, data, code, scoped verification receipts and replay instructions. The four annual packages are also included inside the atlas source bundle. Each archive extracts into its own source root. GitHub reading pages and repository-wide indexes are additional publication material outside these historical bundles.

The 2025 and atlas archives are documented public derivatives: two occurrences of an opaque internal file identifier were removed from ancillary retrieval metadata. All mathematical source bodies and generated reports remain intact. See the [redaction record](../verification/PUBLICATION_REDACTIONS.md) for original-versus-public checksums.
